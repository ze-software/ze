Use these pages to install Ze, configure a network role, operate the system, and diagnose problems. Feature pages explain what Ze can do. Guides explain how to do it.

Start and install

  • Quickstart: bring up two BGP peers quickly.
  • Install Ze: install the daemon or provision an appliance.
  • Build and install on Ubuntu: compile, install, create zefs, and start SSH.
  • CLI tour: use interactive, one-shot, pipe, and runtime commands.
  • Configuration: understand the hierarchical configuration format.
  • Lifecycle and rollback: reload, restart, archive, update, and recover.

Routing

  • BGP peering: configure peers, groups, families, and capabilities.
  • BGP policy: build import, export, validation, and redistribution policy.
  • BGP resilience: configure refresh, graceful restart, persistence, reflection, and multipath.
  • OSPF, IS-IS, and static routes: bring routing protocols online.
  • BFD: configure fast failure detection.
  • MPLS and RSVP-TE: configure label switching and traffic engineering.

Services and security

  • Firewall and policy routing: protect and steer traffic.
  • FlowSpec protected router: translate FlowSpec into local protection.
  • DDoS mitigation: detect floods and respond locally or upstream.
  • PPPoE, L2TP, and IPsec: configure access and tunnel services.
  • Authentication, authorization, RADIUS, and TACACS+: secure operator access.

Interfaces and automation

  • REST and gRPC: use authenticated management APIs.
  • gNMI: use Capabilities, Get, Set, and Subscribe.
  • Web interface: edit configuration and run commands in the browser.
  • MCP: connect tools, resources, and remote clients.
  • Fleet configuration: distribute configuration to managed nodes.

Diagnose and recover

  • System readiness: run offline doctor checks and inspect runtime health.
  • Production diagnostics: start from symptoms and debug safely.
  • Monitoring: configure flow export, MRT, and operational checks.
  • Debugging tools: trace netlink, capture packets, and inspect state.
  • Logging and audit: inspect operational and security history.
