Pre-release network OS

Ze

Ze is an open-source network operating system for Linux. It speaks BGP, manages network interfaces, programs the FIB, and serves a config editor over SSH and a web UI.

GitHub Development Issues Discord

BGP Engine

Lazy parsing, zero-copy forwarding, negotiated capabilities, and extensive protocol testing.

Network Control

Linux interface management, kernel FIB programming, plugins, telemetry, and automation hooks.

Operator UI

YANG-modeled config, SSH CLI, browser workbench, looking glass, and MCP integration.
