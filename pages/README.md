# Pages

Static files for the project website.

This directory is intended to be published with GitHub Pages. If the repository
uses GitHub Actions for Pages, upload this directory as the Pages artifact.

Assets:

- `assets/ze.svg` is copied from `docs/logo/ze.svg`.
- `assets/zeledon.svg` is extracted from the embedded Zeledon artwork in the
  [Manchester 2026 presentation page](https://thomas.mangin.com/data/html/net-manchester-2026-04-presentation.html)
  so the public site can be deployed without depending on ignored presentation
  output.
