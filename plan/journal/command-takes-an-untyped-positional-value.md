# command-takes-an-untyped-positional-value

`ai/rules/cli.md` requires a closed keyword before any user-supplied value. A
free-form value therefore never sits in an untyped positional slot, where it can
collide with a keyword. Peer commands are the one stated exception: a peer is
addressed by name or by address with no selector keyword before it, as in
`show bgp peer 192.0.2.1 detail`.
