# Record written before the operation succeeds

A command persists a record of what it is about to do. It then fails, and the
work never happens. The record outlives the failure. The next reader cannot
tell it apart from a record of real work, because both are just rows.

| 2026-08-28 | - | `Create` verification-debt shard (`internal/le/commit/prepare.go`) | Second occurrence of the row below, in the native command that replaced the Python helper, so the port carried the ordering across. `recordDebt` is called at `prepare.go`,183, and `nextTag` (`script.go`,161) refuses a tag that is not alnum/dot/underscore/dash at `prepare.go`,206 -- after the rows are already on disk. `tag "fix(bgp)"` therefore left three rows in `plan/verification-debt/5184512c.md` naming a commit that `git log --all --grep` finds zero of.
