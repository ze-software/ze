| 2026-08-14 | spec-web-templ-migration | web workbench form | `templates/component/workbench_form.html` renders a password field as `input type="password" value="{{.Value}}"`. The type attribute masks the characters on screen. It does nothing to the response body. The stored secret travels to the browser in the page source. It reaches view-source, the disk cache, and any proxy or extension that reads the document. No sibling branch in the template has the same exposure, because no other field type holds a secret. The golden capture is what made it visible: `testdata/golden/component/workbench_form--fields.html` line 64 carries the literal password from the test fixture | not fixed, recorded for the post-port fix pass |
