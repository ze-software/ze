# State event emitted without comparing state

An event that names a state transition is emitted from a message that means
"something about this object changed". Every consumer then redoes the work of a
transition that did not happen.

| Date | Spec | Surface | Symptom | Fix |
|------|------|---------|---------|-----|
| 2026-08-11 | fixit-route-removal-protocol-blind | iface monitor | `(*monitor).handleLinkUpdate` (`internal/plugins/iface/netlink/monitor_linux.go`) emits `interface/up` or `interface/down` on EVERY RTM_NEWLINK for a link it already knows, with no comparison against the state it last reported. An MTU change on an up link emits `up`. The link handlers in `internal/component/iface/register.go` then moved a route that had already moved, once per event, under `dhcpMu` | open: not fixed at the emitter. Each consumer was made idempotent instead: the route handlers carry `routeMetricState`. Deduplicating at the emitter also drops the refresh `(*resolver).onLinkEvent` (`internal/component/iface/resolve.go`) takes from these events for a rename or a MAC change |
| 2026-11-06 | - | `exportChanged` (`peer_settings_apply.go`), `peerSettingsEqual` (`reactor_api.go`) | A rebuilt chain with an in-process func member never compares equal under `reflect.DeepEqual`, so a no-op reload raises the export watermark and every stale route re-judges. The comment on `peerSettingsEqual` says `PeerSettings` holds no funcs. | open: `filterapi.Policy` compares definitions, and both sites use that. |
| 2026-11-06 | - | `peerSettingsEqual` (`reactor_api.go`) | `applyHotSwappableSettings` now uses `Policy.SameDecisions`. This site still runs `reflect.DeepEqual` over `ImportPolicy` and `ExportPolicy`, which reaches the running `policychain.Chain`: evaluator funcs never compare equal, and it reads the `refused` counter that routes write. A no-op reload reads as a change. | open: compare both policies with `Policy.SameDecisions`, exclude them from the `DeepEqual` copies, and correct the comment. |
| 2026-11-06 | - | `Session.SendRawMessage`, `writeUpdateBody` with `raw=true`, `noteExportWrite` (`stale_readvertise_chain.go`) | Raw injection runs no export chain, so its write carries no generation and reads as zero. Once the peer's `exportGeneration` is above zero, each reachable raw UPDATE raises `exportPolicyFrom` past its receipt with no policy change, and every older stale route re-judges through the whole chain. | open: a raw write leaves the watermark alone, because it holds no decision that a reload can supersede. |
