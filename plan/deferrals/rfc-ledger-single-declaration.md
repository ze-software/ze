# Deferrals -- rfc-ledger-single-declaration

Work this spec touched and deliberately did not do. Every row names where it goes
rather than only that it was left, because a deferral with no destination is an
absence with a table around it.

Nothing here is a conformance decision. The two scope rulings this spec carried
to the owner were answered on 2026-09-01 and are recorded where they bind, in
`rfc/short/rfc6514.md` and `rfc/short/rfc8362.md`, not here.
