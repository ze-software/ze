# Deferrals

Tracked deferrals from implementation sessions. Every decision to not perform in-scope work
must be recorded here with a destination (receiving spec or explicit cancellation).

A row lives here while the work is **outstanding**, and it must name the spec that owns it
(`ai/rules/deferral-tracking.md`). Filing work in a spec is not finishing it: the row stays
`deferred` until the work lands, which is what keeps the commit gate re-checking that its
home still exists. Close a row (`done`) when the work is implemented, not when it is filed.
Run `/ze-status` for the live backlog.
