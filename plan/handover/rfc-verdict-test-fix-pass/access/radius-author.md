## RFC2866-5-1 design (R5 split), for continuation 6
A row quote is ONE verbatim span of at least 24 chars, so a single table line ("1 Acct-Status-Type") cannot be a row. The obligation-bearing text of §5.13 is the legend (rfc/full/rfc2866.txt:1358-1361) plus Note 1:
1. New `RFC2866-5.13-1` [MUST] "1 Exactly one instance of this attribute MUST be present." (§5.13; the table's 1 rows are Acct-Status-Type and Acct-Session-Id). Move TestRFC2866AcctStatusTypePresent's positive tag here (approval D-15, authradius.TestRFC2866AcctStatusTypePresent) and extend or add a positive asserting exactly one Acct-Session-Id too. Genuine negative (R1 b): exclude.go refuses Acct-Status-Type and Acct-Session-Id as exclusion names (comment at exclude.go ~line 66, schema yang/ze-l2tp-auth-radius-conf.yang) -> new unit: configure the exclusion list with EVERY excludable name, build Start/Interim/Stop, assert exactly one of each "1" attribute remains; plus the parser refusing "acct-status-type"/"acct-session-id".
