Contributing to Ze

Contributions to Ze can be code, documentation, bug reports, or results from trying it with other routers. Development happens in the public repository and issue tracker.

AI-assisted contributions are welcome. We prefer recent, capable models, and this is a recommendation. The contribution policy lists example models and explains the requirements that apply to every contribution.

Code

Contribute a fix

Small, tested changes are welcome: parser fixes, command output fixes, protocol edge cases, docs corrections, and tests that detect incorrect behavior.

Evidence

Bring a trace, lab, or transcript

Reports of tests with other routers, QEMU test results, failing .ci test logs, and browser captures are useful because they show exactly what broke and what should be checked next.

Care

Handle security privately

If an unauthenticated peer can trigger it, or if it can escalate access, use the security policy instead of a public issue.

The contribution contract

Hard requirement

Every contribution requires a sign-off.

Each contribution commit requires a Signed-off-by line, which signifies agreement to Ze's Contributor License Agreement. The commit preparation guide explains how to add it through the repository's commit-script process.

You keep your copyright. What you grant is a broad, non-exclusive license for the Maintainer to use your contribution, including the right to relicense it, alone or combined with the rest of the project, under different license terms.

Why this exists

The CLA lets the maintainer offer a commercial license without seeking fresh permission from every past contributor. Ze remains available to everyone under AGPLv3.

How Ze is funded

Stewardship

Supported by Exa Networks

Ze is currently developed by Thomas Mangin, with his time on the project supported by Exa Networks. There is no subscription tier, no paid support contract, and no separate commercial entity behind it today.

Exa Networks has been backing this work since 2009, when it started with ExaBGP, Ze's predecessor.
