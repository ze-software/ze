# `show bmp rib`

## Ze command

- Syntax: `show bmp rib`
- Registry path: `show bmp rib`
- Mode: Read-only
- Wire method: `ze-show:bmp-rib`
- Global pipes: yes

Show routes received via BMP monitoring sessions. Returns the BMP RIB content. Use this to verify what your collector is seeing from remote peers.
