# `request config artifact import`

Import private bytes into an artifact configuration\.

## Ze command

- Registry path: `request config artifact import`
- Usage: `request config artifact <artifact> import <name> <transfer>`
- Mode: Daemon
- Wire method: `ze-config:artifact-import`
- Backends: any backend
- Task support: optional\: the MCP call is synchronous\, which is the default
- Subcommands: none: this command takes no subcommand
- Answer shape: doc
- Address fields: none
- Column order: none
- Pipes, always: json\, ndjson\, table\, text\, yaml\, raw\, no\-more\, save
- Pipes, on its rows: none
- Pipes, while streaming: log
- Pipes, local process only: save
- Command pipes: none
- Pipe aliases: none

Import complete raw source bytes under one configuration basename through native data import\, preserving other artifact keys and recorded publication fences\. Input need not be valid configuration\.

## Arguments

| Name | Type | Required | Values | Summary | Description |
| --- | --- | --- | --- | --- | --- |
| `artifact` | string | yes | any value of this type | Artifact\. | Artifact for this private operation\; ownership comes only from authentication\. |
| `name` | string | yes | any value of this type | Name\. | Name for this private operation\; ownership comes only from authentication\. |
| `transfer` | string | yes | any value of this type | Transfer\. | Transfer for this private operation\; ownership comes only from authentication\. |
