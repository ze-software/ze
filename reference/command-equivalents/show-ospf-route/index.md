# `show ospf route`

## Ze command

- Syntax: `show ospf route`
- Registry path: `show ospf route`
- Mode: Read-only
- Wire method: `ze-show:ospf-route`
- Global pipes: yes

Show OSPF-computed routes. Lists each prefix with its path type (intra/inter/external-1/2), cost, next-hops, and area.
