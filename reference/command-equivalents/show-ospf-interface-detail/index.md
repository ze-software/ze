# `show ospf interface detail`

## Ze command

- Syntax: `show ospf interface detail`
- Registry path: `show ospf interface detail`
- Mode: Read-only
- Wire method: `ze-show:ospf-interface-detail`
- Pipes, always: json, ndjson, table, text, yaml, raw, no-more, save
