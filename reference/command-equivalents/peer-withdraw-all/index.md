# `peer withdraw all`

Withdraw every on-demand announcement.

## Ze command

- Registry path: `peer withdraw all`
- Usage: `peer <selector> withdraw all`
- Mode: Daemon
- Wire method: `ze-bgp:withdraw-all`
- Backends: any backend
- Task support: optional: the MCP call is synchronous, which is the default
- Subcommands: none: this command takes no subcommand
- Answer shape: not declared
- Address fields: none
- Pipes, always: json, ndjson, table, text, yaml, raw, no-more, save
- Pipes, when the answer has rows: match, count, first, last, display, fill
- Pipes, while streaming: log
- Pipes, local process only: save
- Command pipes: none
- Pipe aliases: none

Type it after peer <selector> to withdraw only the announcements made to those peers.

## Arguments

| Name | Type | Required | Values |
| --- | --- | --- | --- |
| `selector` | string | yes | any value of this type |
