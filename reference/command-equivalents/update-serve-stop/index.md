# `update serve stop`

Stop the update server\.

## Ze command

- Registry path: `update serve stop`
- Usage: `update serve stop`
- Mode: Daemon
- Wire method: `ze-update:update-serve-stop`
- Backends: any backend
- Task support: optional: the MCP call is synchronous, which is the default
- Subcommands: none: this command takes no subcommand
- Answer shape: not declared
- Address fields: none
- Column order: none
- Pipes, always: json, ndjson, table, text, yaml, raw, no-more, save
- Pipes, when the answer has rows: match, count, first, last, display, fill
- Pipes, while streaming: log
- Pipes, local process only: save
- Command pipes: none
- Pipe aliases: none

Requests in flight get five seconds to finish before their connections are closed\. The command answers once the server has ended\.
