Description

Imports one config through the store the daemon owns, so it works while ze
runs. For the daemon's own config, the content is staged as the candidate and
the same reload a SIGHUP runs promotes it: the config becomes active only when
the reload accepts it, and a refused config leaves the active config, its
pointers and the daemon unchanged, with the reload's reason in the refusal.
The import is refused while a confirmed-commit window is open, with the
window's own refusal, and while another change is staged. For any other name,
the content is committed as a new active version, the previous one kept as
rollback, and nothing reloads. The answer carries the name, the version stamp
and the byte count. The content is never recorded: the audit log, the
accounting record, the SSH exec log and the session transcript hold a
placeholder in its place.
