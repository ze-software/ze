# `show static`

## Ze command

- Syntax: `show static`
- Registry path: `show static`
- Mode: Read-only
- Wire method: `ze-show:static`
- Global pipes: yes

Show static routes defined in the configuration. Lists each static route with its prefix, next-hop, and interface.
