request data restore

Restore a configuration now or accept full-store recovery after shutdown.

Description

Select config to stage one configuration through the normal reload, or full
to accept every artifact key for recovery after a clean daemon shutdown and
successful store close. Full recovery verifies an independent immutable copy
before answering, then requests restart only after response delivery. A failed
shutdown prevents replacement. With config and client, a hub updates that served
client's configuration without reloading its own.
