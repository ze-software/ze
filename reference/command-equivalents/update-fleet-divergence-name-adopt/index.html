Description

Makes the configuration the client holds this hub's configuration
for that client, as a new version of client-<name>.conf, and
removes the held copy. The client already runs it, so its next
fetch is answered current and its hold ends. The hash given here
must be the held copy's.

Arguments

NameTypeRequiredValuesSummaryDescription
namestringyesany value of this typeManaged client nameThe name of a managed client, as the client entry of a hub server block names it. The hub keeps one held copy for each client.
versionstringyesany value of this typeDevice configuration hashThe version hash of the client's configuration, as show fleet divergence name answers it. A held copy with another hash is refused, so a decision is made only on the copy the operator saw.
