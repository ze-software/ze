show plugin conformance run

Start a program in declare mode and check it behaves as a plugin.

Description

The program is started in declare mode, the way 'show plugin
declarations' starts a configured plugin, and what it writes is judged with the
checks the daemon applies at Stage 1. One row is written for each check: its
name, the stage it belongs to, a verdict of pass, fail or not-judged, the
reason, and the change that fixes a failure. A behavior this version does not
judge keeps its row with the verdict not-judged, so an answer with no failure
is not full conformance. The command exits 1 when a check failed.
It runs in your own ze process only: the daemon starts no program a remote
caller names, and answers with the command to run in your own shell.
