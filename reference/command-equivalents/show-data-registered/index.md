# `show data registered`

List the key patterns registered by all subsystems.

## Ze command

- Registry path: `show data registered`
- Usage: `show data registered`
- Mode: Read-only
- Wire method: `ze-show:data-registered`
- Backends: any backend
- Task support: optional: the MCP call is synchronous, which is the default
- Subcommands: none: this command takes no subcommand
- Answer shape: tab
- Address fields: none
- Pipes, always: json, ndjson, table, text, yaml, raw, no-more, save, match, count, first, last, display, fill
- Pipes, on its rows: none
- Pipes, while streaming: log
- Pipes, local process only: save
- Command pipes: none
- Pipe aliases: none

Shows you what types of data ZeFS knows about.
