# `set debug timeout`

## Ze command

- Syntax: `set debug timeout`
- Registry path: `set debug timeout`
- Mode: Offline
- Wire method: `not listed`
- Global pipes: no

Set the debug auto-disable timer (e.g. 30m, 1h, 90s; 0 disables).
