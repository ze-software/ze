# `set debug module`

## Ze command

- Syntax: `set debug module`
- Registry path: `set debug module`
- Mode: Offline
- Wire method: `not listed`
- Global pipes: no

Enable debug for a subsystem; optionally set level/flag/scope. E.g. 'set debug module bgp.reactor level debug'.
