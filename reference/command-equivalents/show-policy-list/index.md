# `show policy list`

List all available filter types and named instances.

## Ze command

- Registry path: `show policy list`
- Usage: `show policy list`
- Mode: Read-only
- Wire method: `ze-show:policy-list`
- Backends: any backend
- Task support: optional: the MCP call is synchronous, which is the default
- Subcommands: none: this command takes no subcommand
- Answer shape: not declared
- Address fields: none
- Pipes, always: json, ndjson, table, text, yaml, raw, no-more, save
- Pipes, when the answer has rows: match, count, first, last, display, fill
- Pipes, while streaming: log
- Pipes, local process only: save
- Command pipes: none
- Pipe aliases: none

Shows each filter type and its implementing plugin. Check here when building a new policy chain to see what filters you can use.
