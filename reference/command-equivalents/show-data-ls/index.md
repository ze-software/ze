# `show data ls`

## Ze command

- Syntax: `show data ls`
- Registry path: `show data ls`
- Mode: Read-only
- Wire method: `ze-show:data-ls`
- Answer shape: tab
- Address fields: none
- Pipes, always: json, ndjson, table, text, yaml, raw, no-more, save, match, count, first, last, display, fill
- Pipes, on rows: none
- Pipes, while streaming: log
- Pipes, local process only: save
- Command pipes: none

List everything stored in the ZeFS blob store. Shows all keys and their sizes. Use 'show data cat <key>' to see the content of a specific entry.
