# `show geodns`

## Ze command

- Syntax: `show geodns`
- Registry path: `show geodns`
- Mode: Read-only
- Wire method: `ze-show:geodns`
- Global pipes: yes

GeoDNS server status: enabled, bind addresses/port, client-IP source mode, zones, nameserver/host-set/source counts, and the current SOA serial.
