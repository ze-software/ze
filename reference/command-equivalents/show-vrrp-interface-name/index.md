# `show vrrp interface name [<value>]`

## Ze command

- Syntax: `show vrrp interface name [<value>]`
- Registry path: `show vrrp interface name`
- Mode: Read-only
- Wire method: `ze-show:vrrp-interface`
- Global pipes: yes

Show the VRRP virtual routers on one parent interface. Pass the interface name: show vrrp interface name <interface>.
