delete agent skill

Remove the ze skill from the operator's agent harnesses.

Description

At a shell, removes the ze stub skill Ze installed, for the harness
named or, with no agent or agent all, for every harness found, takes its session-start hook out of the
harness's settings file, and leaves every file and hook Ze did not write. Through the daemon, writes nothing and answers the file a remote agent removes.
