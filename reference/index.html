Reference

Use these pages when you know what you need to look up. They are generated from live command, configuration, plugin, and standards data wherever possible.

  • CLI reference: every generated Ze command in one searchable catalog.
  • Configuration reference: the complete YANG configuration tree.
  • Command equivalents: Ze syntax beside Junos, IOS XR, SR OS, and VyOS.
  • Plugin catalog: runtime plugins, dependencies, configuration roots, and source ownership.
  • RFC status: implemented RFCs, partial support, and remaining gaps.
  • Feature status: the detailed implementation and maturity inventory.
  • Dependencies: direct Go packages and why Ze uses them.
  • Glossary: routing, policy, configuration, operator, and testing terms.
  • Deprecated options: removed syntax and its replacement.

For procedures, start with the guides. For system design, use architecture.

Ze is AGPLv3 open source.
