# Ze Go Style: names

The detail behind "Names" in [the Go style core](../ze-go-style.md), which
states the first rules.

A great name captures what a thing is or does, and it proves that the author
understood the domain. Take the time to find it.

When no order is obviously right, sort alphabetically. Go casing and the
package glossary: [`go-conventions.md`](../go-conventions.md).
