**Purpose:** Defines additional attributes for RADIUS (RFC 2865/2866)
to support EAP, ARAP, and accounting extensions including Gigaword
counters for sessions exceeding 4GB.

**Scope:** Extends the base RADIUS attribute set. Relevant to BNG:
the Gigaword attributes allow accurate accounting for high-bandwidth
subscriber sessions.

## Gigaword Accounting Attributes (Section 5.1-5.2)

32-bit RADIUS counters (Acct-Input-Octets, Acct-Output-Octets) wrap
at 2^32 bytes (~4.3GB). Gigaword attributes track the number of times
each counter has wrapped.

| Type | Name | Format | Notes |
|------|------|--------|-------|
| 52 | Acct-Input-Gigawords | Integer | Times Acct-Input-Octets wrapped 2^32 |
| 53 | Acct-Output-Gigawords | Integer | Times Acct-Output-Octets wrapped 2^32 |

**Reconstruction:** Total bytes = (Gigawords * 2^32) + Octets.

**Presence rules:**
- Present only in Accounting-Request records where Acct-Status-Type
  is Stop or Interim-Update.
- Only included when the counter value is non-zero (i.e., when the
  32-bit octet counter has wrapped at least once).

## NAS-Port-Id (Section 5.17)

Type 87. The value is UTF-8 text naming the port of the NAS that is
authenticating the user, in the sense of a physical connection rather than a
TCP or UDP port number. Length is 3 or more, so the text is never empty.

The attribute is used only in Access-Request and Accounting-Request packets.
It exists for a NAS that cannot conveniently number its ports: such a NAS names
them instead. Section 5.19's table allows 0-1 instances in an Access-Request,
and Section 5.19 also allows 0-1 in an Accounting-Request.

## Implementation Constraints

- Gigaword computation: `gigawords = total_bytes >> 32`,
  `octets = total_bytes & 0xFFFFFFFF`.
- Accounting servers MUST handle the absence of Gigaword attributes
  (backward compatibility with RFC 2866-only implementations).
- The NAS computes Gigawords from the actual byte count; it does not
  independently track wrap events.
