## Purpose

Describes the two flavours of traditional, outbound NAT: Basic NAT, which
translates a private source address to one from a pool of global addresses, and
Network Address Port Translation (NAPT), which also translates the TCP/UDP port
(and the ICMP query identifier) so many private hosts share one global address.

## Operations (§4)

| Packet | Basic NAT rewrite | NAPT rewrite in addition |
|--------|-------------------|--------------------------|
| Any IP | source address outbound, destination address inbound; IP header checksum | - |
| TCP/UDP | pseudo-header checksum in the TCP/UDP header | source port outbound, destination port inbound |
| ICMP query | nothing beyond the IP header | query identifier and the ICMP checksum |
| ICMP error | embedded IP header address and checksum, ICMP checksum, outer IP header | embedded transport port |
| FTP PORT/PASV | ALG rewrites the ASCII address (§4.4) | and the ASCII port octets |

§4.2 gives the incremental checksum adjustment algorithm (even offsets and even
lengths only).
