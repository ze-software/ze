## Purpose

Defines the externally observable behavior a NAT must have for unicast UDP so
that NAT traversal (STUN, ICE) and UDP applications work: how mappings are
allocated, filtered, refreshed and timed out, how ports are assigned, how
hairpinning, ICMP and fragments are handled.

## Behavior Vocabulary (§4, §5)

| Behavior | Values | Required |
|----------|--------|----------|
| Mapping | Endpoint-Independent, Address-Dependent, Address and Port-Dependent | Endpoint-Independent (REQ-1) |
| IP address pooling | Arbitrary, Paired | Paired RECOMMENDED (REQ-2) |
| Port assignment | Preservation, Overloading, none | never Overloading (REQ-3) |
| Mapping refresh | Outbound, Inbound | Outbound true (REQ-6) |
| Filtering | Endpoint-Independent, Address-Dependent, Address and Port-Dependent | RECOMMENDED EIF or ADF (REQ-8) |
| Hairpinning | External source IP address and port | required (REQ-9) |

## Timers

| Name | Default | Range | Behavior |
|------|---------|-------|----------|
| UDP mapping timer | five minutes or more RECOMMENDED | not below two minutes, except well-known destination ports | refreshed by outbound traffic |
| Linux nf_conntrack_udp_timeout | 30 s | sysctl | unreplied flow; ze does not change it |
| Linux nf_conntrack_udp_timeout_stream | 120 s | sysctl | flow seen in both directions |

## Pitfalls

- **Interop**: STUN and ICE classify a Linux masquerade as endpoint-independent
  mapping with address-and-port-dependent filtering in the uncontended case;
  under port contention the mapping becomes endpoint-dependent.
- **Timers**: the Linux 30-second unreplied UDP timeout is the usual cause of
  one-way UDP flows (keepalives, SIP REGISTER over UDP) losing their mapping.
