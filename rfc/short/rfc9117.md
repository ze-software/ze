**Purpose:** Relaxes the RFC 8955 FlowSpec validation procedure. A FlowSpec rule
originated inside the Local Domain (empty AS_PATH, or confederation segments
only) is feasible without an originator match, and an eBGP-learned rule is
checked against the left-most AS of the best-match unicast route instead of the
neighboring AS, so FlowSpec can cross a route server that does not prepend its
own AS.

**Scope:** IPv4 and IPv6 FlowSpec (SAFI 133) and FlowSpec VPN (SAFI 134)
feasibility, on receipt. No wire format change.

## Ze

`flowSpecASPath` reads the left-most AS_SEQUENCE ASN and whether the path holds
only confederation segments (AS_CONFED_SEQUENCE or AS_CONFED_SET; an AS_SET first
segment yields no left-most ASN). `flowSpecAuthorized` then requires a covering
best-match unicast route, accepts condition (b.1) or (b.2), and for an external
session compares the left-most ASNs. Condition (b.2) is always enabled: Ze has no
configuration that disables it (the Section 4.1 MAY) and no policy that permits a
non-empty AS_PATH (the Section 4.1 extension). Ze does not enforce the original
RFC 4271 Section 6.3 neighboring-AS rule for FlowSpec, which Section 7 leaves
optional.
