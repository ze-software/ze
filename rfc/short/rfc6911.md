**Purpose:** Defines five RADIUS attributes for IPv6 access networks:
Framed-IPv6-Address (168), DNS-Server-IPv6-Address (169),
Route-IPv6-Information (170), Delegated-IPv6-Prefix-Pool (171) and
Stateful-IPv6-Address-Pool (172).

## Attributes (Section 3)

| Type | Name | Length | Value |
|------|------|--------|-------|
| 168 | Framed-IPv6-Address | 18 | IPv6 address for the RG/host NAS-facing interface |
| 169 | DNS-Server-IPv6-Address | 18 | IPv6 address of a DNS server, order preserved |
| 170 | Route-IPv6-Information | 4..20 | Reserved(1), Prefix-Length(1), Prefix(0..16), announced as an RFC 4191 Route Information Option |
| 171 | Delegated-IPv6-Prefix-Pool | >=3 | pool name for DHCPv6-PD |
| 172 | Stateful-IPv6-Address-Pool | >=3 | pool name for stateful DHCPv6 addresses |

## Compliance Checklist

- [ ] [RFC6911-3.3-1] [MUST] The bits in the prefix after the prefix length, if any, are reserved and MUST be initialized to zero. (§3.3)
- [ ] [RFC6911-3.4-1] [MUST] If a NAS does not support prefix pools, the NAS MUST ignore this Attribute. (§3.4)
- [ ] [RFC6911-3.5-1] [MUST] If a NAS does not support address pools, the NAS MUST ignore this Attribute. (§3.5)
- [ ] [RFC6911-3.2-3] [SHOULD] If more than one DNS-Server-IPv6-Address Attribute is present in the Access- Accept packet, the addresses from the Attributes SHOULD be copied in the same order as received. (§3.2)
- [ ] [RFC6911-3.4-2] [SHOULD] The Delegated-IPv6-Prefix-Pool Attribute contains the name of an assigned pool that SHOULD be used to select an IPv6 delegated prefix for the user on the NAS. (§3.4)
- [ ] [RFC6911-3.5-2] [SHOULD] The Stateful-IPv6-Address-Pool Attribute contains the name of an assigned pool that SHOULD be used to select an IPv6 address for the user on the NAS. (§3.5)
- [ ] [RFC6911-3.1-1] [MAY] It MAY be used in Access-Accept packets and MAY appear multiple times. (§3.1)
- [ ] [RFC6911-3.1-2] [MAY] It MAY be used in an Access-Request packet as a hint by the NAS to the RADIUS server that it would prefer this IPv6 address, but the RADIUS server is not required to honor the hint. (§3.1)
- [ ] [RFC6911-3.2-1] [MAY] This Attribute MAY be included multiple times in Access- Accept packets when the intention is for a NAS to announce more than one DNS server address to an RG/host. (§3.2)
- [ ] [RFC6911-3.2-2] [MAY] The Attribute MAY be used in an Access-Request packet as a hint by the NAS to the RADIUS server regarding the DNS IPv6 address, but the RADIUS server is not required to honor the hint. (§3.2)
- [ ] [RFC6911-3.3-2] [MAY] It MAY be used in an Access-Request packet as a hint by the NAS to the RADIUS server, but the RADIUS server is not required to honor the hint. (§3.3)
- [ ] [RFC6911-3.4-3] [MAY] It MAY be used in an Access-Request packet as a hint by the NAS to the RADIUS server regarding the pool, but the RADIUS server is not required to honor the hint. (§3.4)
