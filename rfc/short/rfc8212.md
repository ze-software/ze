**Purpose:** Changes the RFC 4271 default for EBGP sessions: with no explicit Import Policy, received routes are not eligible for the Decision Process, and with no explicit Export Policy, no route is advertised.

**Scope:** EBGP sessions only (customers, peers, confederation boundaries), every enabled address family (§1). IBGP sessions are not affected. No wire format.

**Errata:** None affecting implementation.

## Terminology (§2)

| Term | Meaning |
|------|---------|
| Import Policy | A local policy applied to the Adj-RIBs-In. Its result is the set of routes the Decision Process considers |
| Export Policy | A local policy applied in selecting the Adj-RIBs-Out |

## Changes to RFC 4271 (§3)

| RFC 4271 section | Added rule |
|------------------|------------|
| 9.1 Decision Process, after the fifth paragraph | An EBGP peer's Adj-RIB-In routes are not eligible without an explicit Import Policy |
| 9.1.3 Phase 3: Route Dissemination, after the third paragraph | Nothing is added to an EBGP peer's Adj-RIB-Out without an explicit Export Policy |

A speaker MAY offer a configuration option to deviate from both.

## Ze Mapping

| Concern | Ze today |
|---------|----------|
| Policy presence | `filter { import { ... final accept/reject; } }` at bgp, group and peer level; `final` is mandatory once the container exists (internal/component/bgp/config/redistribution.go::parsePolicyDisposition) |
| Absent policy | `filterapi.Policy{}` is an absent policy. `AcceptsAtEnd(external)` answers false for it on an EBGP session and true on an IBGP one; a configured policy answers its own `final` (internal/component/bgp/filterapi/policy.go) |
| Absent import, EBGP | A received announcement is withheld from the Decision Process and from every consumer; withdrawals and End-of-RIB still pass (internal/component/bgp/reactor/filter_ordered.go::runIngressPolicyChain) |
| Absent export, EBGP | No route reaches the peer from any egress path: forwarding, config `update` blocks, API text and raw injection, the ExaBGP bridge and redistribution (filter_ordered.go::runEgressPolicyChain, egress_inject_filter.go) |
| Operator view | Peer detail, `show policy chain` and policy dry-run report `final-source rfc8212`, and an established EBGP session with an absent direction logs a warning naming the editor command that sets one (reactor/rfc8212_warning.go) |
| Deviation option (§3 MAY) | None. Ze offers no switch that restores accept-without-policy; an operator writes `final accept` explicitly |

## Compliance Checklist

- [ ] [RFC8212-3-1] [SHALL NOT] Routes contained in an Adj-RIB-In associated with an EBGP peer SHALL NOT be considered eligible in the Decision Process if no explicit Import Policy has been applied. (§3)
- [ ] [RFC8212-3-2] [SHALL NOT] Routes SHALL NOT be added to an Adj-RIB-Out associated with an EBGP peer if no explicit Export Policy has been applied. (§3)
- [ ] [RFC8212-3-3] [MAY] A BGP speaker MAY provide a configuration option to deviate from the following updated behaviors. (§3)
