# RFC 6071 - IP Security (IPsec) and Internet Key Exchange (IKE) Document Roadmap

## Meta

| Field | Value |
|-------|-------|
| RFC | 6071 |
| Title | IP Security (IPsec) and Internet Key Exchange (IKE) Document Roadmap |
| Status | Informational |
| Date | February 2011 |
| Authors | S. Frankel, S. Krishnan |

**Purpose:** Catalogues every RFC in the IPsec/IKE ecosystem, maps which document covers which function, and records the algorithm requirement levels (MUST/SHOULD/MAY) for ESP, AH, IKEv1, and IKEv2. Use this summary to validate that Ze's IPsec config references valid algorithm combinations and correct RFC sources.

## Core Document Stack

| Layer | Current (v3) | Obsolete (v2) | Function |
|-------|-------------|---------------|----------|
| Architecture | RFC 4301 | RFC 2401 | SPD, SAD, processing model |
| ESP | RFC 4303 | RFC 2406 | Encryption + optional integrity |
| AH | RFC 4302 | RFC 2402 | Integrity only (no encryption) |
| IKEv2 | RFC 5996 | RFC 4306 | SA negotiation, key exchange |
| IKEv1 | (obsolete) | RFC 2409 + RFC 2408 + RFC 2407 | Legacy SA negotiation |

### Architecture Hierarchy

```
RFC 4301 (Architecture)
 +-- RFC 4303 (ESP)
 |    +-- Encryption algorithms (RFC 3602, RFC 3686, ...)
 |    +-- Integrity algorithms (RFC 2404, RFC 3566, ...)
 |    +-- Combined-mode algorithms (RFC 4106, RFC 4309, ...)
 +-- RFC 4302 (AH)
 |    +-- Integrity algorithms (same set minus encryption)
 +-- RFC 5996 (IKEv2)
      +-- RFC 4307 (IKEv2 algorithm requirements)
      +-- Extensions (MOBIKE, session resumption, redirect, ...)
```

## Algorithm Requirement Levels

Requirement terms: MUST (mandatory), MUST- (deprecated but mandatory), SHOULD+ (strongly preferred), SHOULD (recommended), SHOULD- (deprecated but recommended), MAY (optional). "optional" means permitted but not specifically recommended. "N/A" means not applicable.

## Key Architecture Changes: v2 to v3

| Feature | IPsec-v2 (RFC 2401) | IPsec-v3 (RFC 4301) |
|---------|---------------------|---------------------|
| SA identification | SPI + protocol + destination | SPI + optional protocol (unicast) |
| SPD | Ordered | Decorrelated (order-independent) |
| AH | MUST implement | MAY implement |
| ESP-NULL | MUST | MAY |
| Combined-mode (AEAD) | Not supported | Supported (RFC 4303) |
| Extended Sequence Numbers | Not supported | Supported (RFC 4304) |

## Document Categories

The roadmap organizes IPsec/IKE RFCs into these groups:

1. **Architecture** (RFC 4301)
2. **ESP/AH protocols** (RFC 4302, RFC 4303)
3. **Encryption algorithms** (RFC 2410, RFC 2451, RFC 3602, RFC 3686, RFC 4312, RFC 4196)
4. **Combined-mode algorithms** (RFC 4106, RFC 4309, RFC 4543, RFC 5282)
5. **Integrity algorithms** (RFC 2403, RFC 2404, RFC 2857, RFC 3566, RFC 4494, RFC 4868)
6. **IKE protocols** (RFC 5996, RFC 2409)
7. **IKE extensions** (MOBIKE, redirect, session resumption, EAP-only auth)
8. **Algorithm requirements** (RFC 4835, RFC 4307, RFC 4109)
9. **DH groups** (RFC 3526, RFC 5903, RFC 5114)
10. **PRFs** (RFC 4434, RFC 4615)
11. **PKI/certificates** (RFC 4945, RFC 4809, RFC 4806)
12. **IPsec policy** (RFC 3585, RFC 3586)
13. **MIBs** (RFC 4807)
14. **Multicast** (RFC 5374, RFC 3547)
15. **BTNS** (RFC 5386, RFC 5387, RFC 5660)
16. **IP compression** (RFC 3173)
