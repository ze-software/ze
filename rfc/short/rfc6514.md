## Overview

Specifies the BGP encodings and procedures for multicast in MPLS/BGP IP VPNs: the
MCAST-VPN NLRI and its seven route types, the PMSI Tunnel attribute that binds a
VPN multicast flow to a provider tunnel, and the auto-discovery and C-multicast
route exchange between PEs.

Scope: AFI 1 (IPv4) or AFI 2 (IPv6) with SAFI 5 (MCAST-VPN). The AFI decides
whether the multicast source and group addresses in S-PMSI A-D routes, Source
Active A-D routes and C-multicast routes are IPv4 or IPv6 (Section 4). Section 10
also defines SAFI 129 for the routes a PE uses only for upstream multicast hop
selection.

## Wire Formats

### MCAST-VPN NLRI (Section 4)

```
   +-----------------------------------+
   |    Route Type (1 octet)           |
   +-----------------------------------+
   |     Length (1 octet)              |
   +-----------------------------------+
   | Route Type specific (variable)    |
   +-----------------------------------+
```

| Field | Offset | Size | Constraints |
|-------|--------|------|-------------|
| Route Type | 0 | 1 | 1..7 defined by this document |
| Length | 1 | 1 | Length in octets of the Route Type specific field |
| Route Type specific | 2 | Length | Format selected by Route Type |

Route types:

| Value | Name | Class |
|-------|------|-------|
| 1 | Intra-AS I-PMSI A-D route | A-D |
| 2 | Inter-AS I-PMSI A-D route | A-D |
| 3 | S-PMSI A-D route | A-D |
| 4 | Leaf A-D route | A-D |
| 5 | Source Active A-D route | A-D |
| 6 | Shared Tree Join route | C-multicast |
| 7 | Source Tree Join route | C-multicast |

### Intra-AS I-PMSI A-D Route, type 1 (Section 4.1)

```
   +-----------------------------------+
   |      RD   (8 octets)              |
   +-----------------------------------+
   |   Originating Router's IP Addr    |
   +-----------------------------------+
```

### Inter-AS I-PMSI A-D Route, type 2 (Section 4.2)

```
   +-----------------------------------+
   |      RD   (8 octets)              |
   +-----------------------------------+
   |      Source AS (4 octets)         |
   +-----------------------------------+
```

A two-octet ASN goes in the two low-order octets of the Source AS field, with the
two high-order octets set to zero.

### S-PMSI A-D Route, type 3 (Section 4.3)

```
   +-----------------------------------+
   |      RD   (8 octets)              |
   +-----------------------------------+
   | Multicast Source Length (1 octet) |
   +-----------------------------------+
   |  Multicast Source (variable)      |
   +-----------------------------------+
   |  Multicast Group Length (1 octet) |
   +-----------------------------------+
   |  Multicast Group   (variable)     |
   +-----------------------------------+
   |   Originating Router's IP Addr    |
   +-----------------------------------+
```

The Multicast Source Length is 32 for an IPv4 C-S and 128 for an IPv6 C-S. The
Multicast Group field carries the C-G address or a C-LDP MP Opaque Value Element,
and its length is 32 for IPv4 and 128 for IPv6. Any other value of either length
field is outside the scope of the document.

### Leaf A-D Route, type 4 (Section 4.4)

```
   +-----------------------------------+
   |      Route Key (variable)         |
   +-----------------------------------+
   |   Originating Router's IP Addr    |
   +-----------------------------------+
```

The Route Key is the whole MCAST-VPN NLRI of the received Inter-AS I-PMSI A-D
route or S-PMSI A-D route that caused this route. A Leaf A-D route is originated
only when the received route carries a PMSI Tunnel attribute with the Leaf
Information Required bit set to 1. Type 4 carries no RD of its own.

### Source Active A-D Route, type 5 (Section 4.5)

```
   +-----------------------------------+
   |      RD   (8 octets)              |
   +-----------------------------------+
   | Multicast Source Length (1 octet) |
   +-----------------------------------+
   |   Multicast Source (variable)     |
   +-----------------------------------+
   |  Multicast Group Length (1 octet) |
   +-----------------------------------+
   |  Multicast Group (variable)       |
   +-----------------------------------+
```

A Multicast Source Length of 0 is outside the scope of the document.

### C-Multicast Route, types 6 and 7 (Section 4.6)

```
   +-----------------------------------+
   |      RD   (8 octets)              |
   +-----------------------------------+
   |    Source AS (4 octets)           |
   +-----------------------------------+
   | Multicast Source Length (1 octet) |
   +-----------------------------------+
   |   Multicast Source (variable)     |
   +-----------------------------------+
   |  Multicast Group Length (1 octet) |
   +-----------------------------------+
   |  Multicast Group   (variable)     |
   +-----------------------------------+
```

For a Shared Tree Join route the Multicast Source field carries the C-RP address.
For a Source Tree Join route it carries the C-S address.

### PMSI Tunnel Attribute (Section 5)

Type code: 22. Optional transitive.

```
   +---------------------------------+
   |  Flags (1 octet)                |
   +---------------------------------+
   |  Tunnel Type (1 octets)         |
   +---------------------------------+
   |  MPLS Label (3 octets)          |
   +---------------------------------+
   |  Tunnel Identifier (variable)   |
   +---------------------------------+
```

```
    0 1 2 3 4 5 6 7
   +-+-+-+-+-+-+-+-+
   |  reserved   |L|
   +-+-+-+-+-+-+-+-+
```

| Field | Offset | Size | Constraints |
|-------|--------|------|-------------|
| Flags | 0 | 1 | Bit 7 is Leaf Information Required (L); the rest are reserved |
| Tunnel Type | 1 | 1 | 0..7 defined below |
| MPLS Label | 2 | 3 | High-order 20 bits carry the label value; all zero means no label |
| Tunnel Identifier | 5 | variable | Syntax selected by Tunnel Type |

| Tunnel Type | Name | Tunnel Identifier |
|-------------|------|-------------------|
| 0 | No tunnel information present | absent |
| 1 | RSVP-TE P2MP LSP | Extended Tunnel ID, Reserved, Tunnel ID, P2MP ID (RFC 4875 SESSION object) |
| 2 | mLDP P2MP LSP | P2MP FEC Element |
| 3 | PIM-SSM Tree | P-Root Node Address, P-Multicast Group |
| 4 | PIM-SM Tree | Sender Address, P-Multicast Group |
| 5 | BIDIR-PIM Tree | Sender Address, P-Multicast Group |
| 6 | Ingress Replication | Unicast tunnel endpoint IP address of the local PE |
| 7 | mLDP MP2MP LSP | MP2MP FEC Element |

### PE Distinguisher Labels Attribute (Section 8)

Type code: 27. Optional transitive.

```
   +---------------------------------+
   |           PE Address            |
   +---------------------------------+
   |     Label (3 octets)            |
   +---------------------------------+
   .......
   +---------------------------------+
   |           PE Address            |
   +---------------------------------+
   |     Label (3 octets)            |
   +---------------------------------+
```

The Label field holds an MPLS label in 3 octets, where the high-order 20 bits are
the label value.

### UMH NLRI, SAFI 129 (Section 10)

```
   +---------------------------+
   |   Length (1 octet)        |
   +---------------------------+
   |   Prefix (variable)       |
   +---------------------------+
```

Length is in bits. Prefix is an RFC 4364 Route Distinguisher prepended to an IPv4
or IPv6 address prefix, followed by enough trailing bits to end on an octet
boundary. The value of the trailing bits is irrelevant.

## Validation

| Check | Valid | Invalid action |
|-------|-------|----------------|
| PMSI Tunnel Type field | A tunnel type the router defines | Attribute is malformed (Section 5) |
| PMSI Tunnel Identifier | Parses as an identifier of the declared tunnel type | Attribute is malformed (Section 5) |
| Malformed PMSI Tunnel attribute with Partial bit set | n/a | SHOULD treat the Update as though all its routes were withdrawn |
| PE Distinguisher Labels PE Address | A unicast address | Attribute is malformed (Section 8) |
| PE Distinguisher Labels length, IPv4 PE Address | Multiple of 7 | Attribute is malformed (Section 8) |
| PE Distinguisher Labels length, IPv6 PE Address | Multiple of 19 | Attribute is malformed (Section 8) |
| Malformed PE Distinguisher Labels attribute with Partial bit set | n/a | SHOULD treat the Update as though all its routes were withdrawn |
| Source Active A-D route, Multicast Group in the SSM range | Group outside the SSM range | MUST be discarded on receipt, and MUST NOT be advertised (Section 4.5) |
| C-multicast route, Route Target against the VRF C-multicast Import RTs | One RT matches | PE SHOULD discard the route (Section 11.3) |
| C-multicast route, Multicast Source against the VPN-IP routes the PE advertised from the VRF | One matches | PE SHOULD discard the route (Section 11.3) |
| Route with MCAST-VPN SAFI received from a CE | n/a | PE MUST NOT accept it (Section 17) |

The route type length field is one octet, so the Route Type specific field cannot
exceed 255 octets.

## Pitfalls

- **Type 4 has no RD.** A Leaf A-D route starts with a variable-length Route Key,
  not a Route Distinguisher. Code that reads the first 8 octets of every MCAST-VPN
  route type as an RD mislabels type 4.
- **The Length field is one octet.** The Route Type specific field cannot exceed
  255 octets, which bounds the Route Key a Leaf A-D route can echo.
- **Source AS is four octets even for a two-octet ASN.** The two high-order octets
  are zero. Errata 5724 records that an IPv6 Originating Router's IP Address, which
  RFC 6515 permits, does not fit the field Section 11.1.3 tells a PE to copy it into.
- **PMSI_TUNNEL is optional TRANSITIVE.** A speaker that does not read it must
  still pass it along with the Partial bit set, per RFC 4271 Section 9.
- **The address family of the addresses is decided by the MP_REACH AFI, not by the
  length field alone.** AFI 1 means the source and group addresses are IPv4, AFI 2
  means IPv6 (Section 4).
- **The malformed-attribute response is SHOULD, not a session reset.** Sections 5
  and 8 both ask for treat-as-withdraw, and only when the Partial bit is set.

## Compatibility

MCAST-VPN is negotiated with RFC 4760 capability code 1, AFI 1 or 2 and SAFI 5.
A speaker that does not advertise the capability never receives the family, so
there is no fallback to negotiate.
