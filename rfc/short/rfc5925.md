## Overview

Specifies the TCP Authentication Option, the replacement for the RFC 2385 TCP MD5 signature option: a keyed MAC over each segment with traffic keys derived from a master key, key rollover without session reset, and protection of the TCP header as well as the payload. Ze implements RFC 2385 TCP MD5 and does not implement TCP-AO.
