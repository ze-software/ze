## Overview

Specifies BGP confederations: an AS is divided into member-ASes that speak eBGP to each other, with AS_CONFED_SEQUENCE and AS_CONFED_SET path segments that are stripped before the path leaves the confederation. Ze implements route reflection (RFC 4456) as its iBGP scaling mechanism and does not implement confederations.

**Updated by RFC 9774 (AS_SET deprecation).** RFC 9774 Section 3 deprecates the
AS_CONFED_SET segment this document defines: a BGP speaker "MUST NOT advertise
BGP UPDATE messages containing AS_SETs or AS_CONFED_SETs" and treats a received
UPDATE carrying one as withdrawn. Ze, which does not implement confederations,
applies both halves to AS_CONFED_SET (`rfc/short/rfc9774.md`).
