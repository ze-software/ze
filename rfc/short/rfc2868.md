**Purpose:** Defines ten RADIUS attributes a RADIUS server uses to tell a
tunnel initiator (such as an L2TP LAC) to build a compulsory tunnel:
Tunnel-Type (64), Tunnel-Medium-Type (65), Tunnel-Client-Endpoint (66),
Tunnel-Server-Endpoint (67), Tunnel-Password (69), Tunnel-Private-Group-ID
(81), Tunnel-Assignment-ID (82), Tunnel-Preference (83),
Tunnel-Client-Auth-ID (90) and Tunnel-Server-Auth-ID (91), with a Tag octet
grouping attributes of one tunnel and a salted encryption for
Tunnel-Password.

**Errata:** Section 3.10 (Tunnel-Server-Auth-ID) repeats the Section 3.9
sentence naming Tunnel-Client-Auth-ID; both rows quote the text as printed.
