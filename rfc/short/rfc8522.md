**Purpose:** Defines a RESTful HTTP API for network looking glasses: a client asks the server, by HTTP GET under `/.well-known/looking-glass`, to run a predefined command on a selected router, and the server answers in JSend-formatted JSON.

**Scope:** HTTP API, Informational, Independent Submission. No BGP wire format.

**Errata:** None affecting implementation.

## Roles (§2)

| Role | Does |
|------|------|
| Client | Sends HTTP GET calls with every parameter the command needs |
| Server | Runs only predefined commands on the selected router, answers in JSON |
| Router | Executes the command; never talks to the client directly |

The server-to-router protocol is unspecified (Telnet, SSH, NETCONF, serial console). All parameters and values are case insensitive.

## URI Structure (§2.1, §2.2)

`https://<host>/.well-known/looking-glass/v1/<method parameters>?<query parameters>`

| Query parameter | Type | Default | Meaning |
|-----------------|------|---------|---------|
| protocol | String | `1,1` | AFI and optional SAFI, comma-separated |
| router | String | first router | Router by name |
| routerindex | Number | `0` | Router by list position |
| random | String | none | Cache buster; the server ignores its value |
| vrf | String | none | Routing table |
| runtime | Number | `30` | Execution limit in seconds, 0 disables |
| format | String | `text/plain` | Output media types in preference order |

## Response (§2.3, Appendix A)

HTTP `Content-Type: application/json`, body in JSend.

| status | Required keys | Optional keys | HTTP code |
|--------|---------------|---------------|-----------|
| success | status, data | | 200 |
| fail | status, data | | 200 |
| error | status, message | code, data | 400 client, 500 server, 502 router, 504 timeout |

`data` of a success carries `performed_at` (UTC ISO 8601, required), `runtime` (seconds, required), `router` (may), `output` (should), `format` (should). Extra information goes inside `data`.

## Functions (§3)

| Function | URI | Status |
|----------|-----|--------|
| ping | `v1/ping/{host}` | mandatory |
| traceroute | `v1/traceroute/{host}` | optional |
| show route | `v1/show/route/{addr}` | mandatory |
| show bgp | `v1/show/bgp/{addr}` | optional |
| show bgp summary | `v1/show/bgp/summary` | optional |
| show bgp neighbors | `v1/show/bgp/neighbors/{addr}` | optional |
| router list | `v1/routers` | mandatory (organizational) |
| router details | `v1/routers/{number}` | mandatory (organizational) |
| commands | `v1/cmd` | mandatory (organizational) |

Every function is a GET and none changes server state (§3).
