# RFC 3209 corrections

Why a requirement row of `rfc/short/rfc3209.md` changed level, text, or citation.
The summary is the working document; this file is the record the level
ratchet reads (`checkLevelRatchet`, `internal/le/rfc/check_ratchets.go`).

Correction 2026-09-21: `RFC3209-4.1-2` was published [MUST]. Section 4.1 opens the LABEL
object at permission strength, in its first sentence: "Labels MAY be carried in Resv
messages." The MUST that follows in the same paragraph binds the PLACEMENT of a label
that is carried, not the carrying of one, and `RFC3209-4.1-1` already holds it. The row
is corrected to [MAY].

Retired 2026-09-26: `RFC3209-x-1` said PATH messages MUST include the Router Alert IP
option. RFC 3209 does not state it: read §1 to §7 (every section of the text), and no
sentence names Router Alert. RFC 2205 states it ("RSVP must be able to cause Path,
PathTear, and ResvConf message to be sent with the Router Alert IP option"), and its
summary already carries the obligation as RFC2205-x-1. Both units that tagged this row,
TestRFC2205PathNeverLeavesWithoutRouterAlertCarrier (negative) and
TestIntegrationRSVPPathCarriage (positive), already carry RFC2205-x-1 with the same
polarity, so the two RFC3209 tag lines were deleted and the obligation stays on the
RFC 2205 row.

Retired 2026-09-27: `RFC3209-4.1-3` states an obligation RFC 3209 does not carry. Read §4.1 and the whole text: RFC 3209 reserves no label value. RFC 3032 §2.1 lists the reserved labels, ending "Values 4-15 are reserved." Under owner decision D-10 that list is now row RFC3032-2.1-1 of rfc/short/rfc3032.md, and the one tag, on TestLSPTableAllocateSkipsReservedLabels in internal/plugins/rsvpte/fsm_test.go, moved to it.

Retired 2026-09-27: `RFC3209-2.5-1` states an obligation RFC 3209 does not carry. Read §2.5, which is make-before-break rerouting, then the whole text: RFC 3209 relies on RSVP refresh and never states it. RFC 2205 §2.3 does: "RSVP soft state is created and periodically refreshed by Path and Resv messages." Under owner decision D-10 that is now row RFC2205-2.3-1 of rfc/short/rfc2205.md, and both tags, on TestRefreshDoesNotStampEgressPSB and TestRefreshResendsPathAndResv in internal/plugins/rsvpte/softstate_test.go, moved to it.
