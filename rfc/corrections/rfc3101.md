# RFC 3101 corrections

Correction 2026-09-26: `RFC3101-3.2-2` was extracted at MUST. §3.2 step (2) states the
duplicate-translation rule as a recommendation: "the calculating router has the highest
router ID amongst NSSA translators that have originated a functionally equivalent Type-5
LSA (i.e. same destination, cost and non-zero forwarding address) and that are reachable
over area 0 and the NSSA, then a Type-5 LSA should be generated". Same requirement id, the
row now quotes that span at SHOULD.

Correction 2026-09-30: `RFC3101-3.1-2` quotes the list-membership sentence of §3.1, and its
tests had also carried the election rule that follows it. On the main thread's ruling (R31)
that rule, "If there exists another border router in this list whose router-LSA has bit Nt
set or who has a higher router ID, then its NSSATranslatorState is disabled.", is now its
own row, `RFC3101-3.1-4`, a gap row naming a disclosed deviation: Ze counts a router only
when its Nt-bit is set, so a higher-router-ID `translate never` border router cannot leave
the NSSA without a translator. -2 keeps the reachability tests; same level for both rows.
