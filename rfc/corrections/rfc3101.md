# RFC 3101 corrections

Correction 2026-09-26: `RFC3101-3.2-2` was extracted at MUST. §3.2 step (2) states the
duplicate-translation rule as a recommendation: "the calculating router has the highest
router ID amongst NSSA translators that have originated a functionally equivalent Type-5
LSA (i.e. same destination, cost and non-zero forwarding address) and that are reachable
over area 0 and the NSSA, then a Type-5 LSA should be generated". Same requirement id, the
row now quotes that span at SHOULD.
