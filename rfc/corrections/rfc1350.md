# RFC 1350 row corrections

Retired 2026-09-30: `RFC1350-5-2` binds a host that receives an octet file and then returns it, which Ze does not implement. §5 reads "If a host receives a octet file and then returns it, the returned file must be identical to the original." Ze's TFTP server refuses WRQ (`serve` in `internal/plugins/tftpserver/handler.go`) and Ze has no TFTP client, so it never receives a file and the round trip cannot occur (main-thread ruling R2). Its two tags, on `TestTFTPReadRequest` and `TestTFTPReadLargeFile`, showed only that a stored file is sent unchanged, which no row of RFC 1350 states, so they were dropped. Extraction site 5:2 is now excluded as binds-another-role, and the Enrolment reason counts ten MUST rows, eight met.
