# RFC 7854 corrections

Why a requirement row of `rfc/short/rfc7854.md` changed level, text, or citation.
The summary is the working document; this file is the record the level
ratchet reads (`checkLevelRatchet`, `internal/le/rfc/check_ratchets.go`).

Correction 2026-09-21: `RFC7854-x-11` was published [MUST]. Section 3.3, Lifecycle of a
BMP Session, states the Termination message at permission strength: "The router MAY send
a Termination message prior to closing the session." The MUST that section 4.5 carries is
a different obligation, on what a router does AFTER it sends one, so it does not raise
this row. The row is corrected to [MAY].
