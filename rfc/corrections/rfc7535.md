# RFC 7535 row corrections

Retired 2026-11-19: `RFC7535-6-1` states no obligation RFC 7535 carries. It was extracted at MUST from §6's last sentence, "DNAME support on AS112 nodes themselves is never required under this proposal.", which says that nothing is required of an AS112 node. Read §1 to §8 and the appendices, then the whole text: RFC 7535 is Informational, has no RFC 2119 key-words section, and no sentence of it obliges an AS112 node to support or to refuse DNAME. The row carried no tag and no audit verdict, so no tag moved. Extraction site 6:2 is now excluded as not-a-requirement.
