# RFC 3579 corrections

Correction 2026-09-30: `RFC3579-3-1` quoted the whole §3 sentence, "The NAS-Port or NAS-Port-Id attributes SHOULD be included by the NAS in Access-Request packets, and either NAS-Identifier, NAS-IP-Address or NAS-IPv6-Address attributes MUST be included.", while its SHOULD clause is already row `RFC3579-3-2`. The row now quotes the MUST clause only, which is what its tags prove: TestRadiusAdminEapAccessRequestNamesTheNAS and TestRadiusAdminEapNamesTheNASWithoutASourceAddress (positive: every request of the EAP conversation names the NAS, with and without a source address), and TestRadiusAdminEapWithNoNASIdentityIsNotSent (negative: an authenticator with no NAS-Identifier and no source address sends no Access-Request), all in internal/component/radius/rfc3579_nas_obligations_test.go. Level and id are unchanged. The SHOULD clause stays row `RFC3579-3-2`, which ze does not meet on the admin login that sends every EAP-bearing Access-Request, because that login has no NAS port (main-thread ruling R5); the row carries a `{gap}` annotation saying so, and the summary's "Support remaining" cell counts it apart from the fourteen MUST-level gaps.
