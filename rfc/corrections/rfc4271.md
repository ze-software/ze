Correction 2026-10-01: a new row, `RFC4271-8.2.2-28`, closes the last §8.2.2 "any other event" forward miss under main-thread ruling R49(a): the Established state's "In response to any other event (Events 9, 12-13, 20-22), the local system:" list. The reading the row is judged under: for Event 21 (header error) and Event 22 (OPEN error), the Event-specific procedures of Section 6.1 and Section 6.2 are the more specific requirements and govern the Error Code, so the NOTIFICATION Ze sends is Message Header Error or OPEN Message Error, not Finite State Machine Error; the §8.2.2 sentence still governs the teardown: delete the routes, set the ConnectRetryTimer to zero, release resources, drop the TCP connection, count the attempt, go to Idle. The row's tests therefore prove Event 21 only: a header with an all-zero Marker or Length 18 draws exactly one NOTIFICATION 1/1 or 1/2 and the full teardown, and a well-formed KEEPALIVE draws none. The row quotes its list up to the last action before the state change, as the other §8.2.2 rows do, and is recorded in the extraction's §8.2.2 unsourced-ids.
