# RFC 3948 corrections

Why a requirement row of `rfc/short/rfc3948.md` changed level, text, or citation, or was
retired. The summary is the working document; this file is the record the level ratchet
reads (`checkLevelRatchet`, `internal/le/rfc/check_ratchets.go`).

Correction 2026-09-27: `RFC3948-4-1` was extracted at MUST strength as "Keepalive interval
MUST be shorter than the NAT binding timeout". Section 4 states no such rule and names no
binding timeout. Its only timing obligation is a recommendation: "A peer SHOULD send a
NAT-keepalive packet if a need for it is detected according to [RFC3947] and if no other
packet to the peer has been sent in M seconds." Same requirement id, corrected text and
level.

Retired 2026-09-27: `RFC3948-2.2-1` states no obligation RFC 3948 carries. It said a
Non-ESP Marker MUST be prepended to IKE packets on port 4500. Read §2.2, then the whole
text, §1 to §6 and Appendix A: §2.2 only defines the marker in the indicative, "A Non-ESP
Marker is 4 zero-valued bytes aligning with the SPI field of an ESP packet", and defers the
header's use to RFC 3947. The prepending is stated by RFC 7296 §2.23, "To tunnel IKE packets
over UDP port 4500, the IKE header has four octets of zeros prepended", which its own row
RFC7296-2.23-3 quotes. Both tags of this row sat on units that already carry an
RFC7296-2.23-3 tag of the same polarity (TestNonESPMarker positive, TestNonESPMarkerESPPacket
negative, internal/component/ike/transport/nat_test.go), so the two tags were deleted rather
than moved, and nothing the tests prove leaves the ledger.

Retired 2026-09-27: `RFC3948-2.1-3` states an obligation RFC 3948 does not carry. Read §2.1, §2.2 and §2.3, then the whole text: RFC 3948 defines the Non-ESP Marker ("A Non-ESP Marker is 4 zero-valued bytes aligning with the SPI field of an ESP packet.") and the NAT-keepalive format, but no sentence tells a receiver how to demultiplex. RFC 7296 §2.23 states it: "it is always possible to distinguish ESP and IKE messages". Under owner decision D-10 that is now row RFC7296-2.23-12 of rfc/short/rfc7296.md, and the two demultiplexing tags, on TestNonESPMarker and TestNonESPMarkerESPPacket in internal/component/ike/transport/nat_test.go, moved to it. The two keepalive tags on TestIsNATKeepalive moved to row RFC3948-2.3-1, the receiver's keepalive rule in §2.3.
