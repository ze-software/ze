# RFC 7313 corrections

Correction 2026-09-30: `RFC7313-4-1` quoted the whole §4 sentence "Before the
speaker starts a route refresh that is either initiated locally, or in response
to a "normal route refresh request" from the peer, the speaker MUST send a BoRR
message." Its tests prove only the refresh ze makes in response to the peer's
request, and ze starts no locally initiated refresh. The row is split on the main
thread's decision: -1 keeps the peer-requested clause and its tests, and the
locally initiated clause is now `RFC7313-4-13`, annotated `{feature-declined}`.
RFC 7313 §4 never requires a locally initiated whole-table refresh, because when
a route entry in the Adj-RIB-Out "changes, only the modified route entry needs to
be advertised". Soft clear, ze's one operator refresh, sends the peer an inbound
ROUTE-REFRESH request and re-advertises nothing. Same level for both rows.
