# RFC 2473 corrections

Correction 2026-09-30: `RFC2473-4.1.1-2` quoted step (c) of Section 4.1.1 up to "being
added at this entry point" and dropped the sentence that closes the step, "The limit
value in the encapsulating option is set to one less than the limit value found in the
packet being encapsulated." The narrowing audit of spec-rfc-verdict-test-fix-pass found
it. The row now quotes the whole step, because the value is part of the obligation and
the tagged tests assert it on the wire. The row's `{not-applicable}` marker is removed:
Ze fills the tunnel entry-point role through the Linux ip6_tunnel datapath it installs
(ai/rules/rfc-compliance.md), so the tests install the tunnel through Ze's netlink
backend and read the outer Tunnel Encapsulation Limit off the underlay.
