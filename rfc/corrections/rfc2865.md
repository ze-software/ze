# RFC 2865 corrections

Why a requirement row of `rfc/short/rfc2865.md` changed level, text, or citation,
or was retired. The summary is the working document; this file is the record the
ratchets read (`checkLevelRatchet`, `checkRetiredRequirements`,
`internal/le/rfc/check_ratchets.go`).

Retired 2026-09-26: `RFC2865-x-1` said to "use constant-time comparison for authenticator
verification", cited to "Implementation Constraints", which is not a section of RFC 2865.
Read §3 (the Response Authenticator), §4.2, §4.4 and §8 Security Considerations, then the
whole text: no sentence mentions timing or constant-time comparison, and §3 only defines
the MD5 value the NAS compares. The row stated a Ze implementation choice at SHOULD level,
not an RFC obligation. It carried no test tag, no extraction mapping and no audit verdict,
so nothing moved.
