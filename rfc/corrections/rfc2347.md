or was retired. The summary is the working document; this file is the record the

Retired 2026-09-30: `RFC2347-x-2` states nothing beyond another row of this
summary. Read §Negotiation (the Negotiation Protocol section, which the summary
cites so because RFC 2347 numbers no section), then the whole text: its quote,
"If multiple options were requested, the client must use those options which
were acknowledged by the server", is the first half of the one sentence that row
RFC2347-x-4 quotes whole, "If multiple options were requested, the client must
use those options which were acknowledged by the server and must not use those
options which were not acknowledged by the server." Under main-thread ruling R5
of spec-rfc-verdict-test-fix-pass the two rows merge into x-4, whose
{not-applicable} annotation now names both halves: the sentence binds a TFTP
client, and Ze ships only the server in `internal/plugins/tftpserver/handler.go`.
Extraction site front:3 now maps to x-4, which leaves `unsourced-ids`. The row
carried no tag and no audit verdict, so no tag moved.
