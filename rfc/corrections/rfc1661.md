Correction 2026-09-30: `RFC1661-5.8-5` quotes the §5.8 Echo-Request and Echo-Reply sentence, "Until the Magic-Number Configuration Option has been successfully negotiated, the Magic- Number MUST be transmitted as zero.", and cites §5.8. The narrowing audit of 2026-09-28 named the same sentence under §5.9, Discard-Request, which no row states. No row is added for it. The obligation binds a sender of a Discard-Request, and Ze sends none: row `RFC1661-5.9-1` carries a `{not-applicable}` annotation recording that the LCPDiscardRequest constant is never written by any producer under internal/. A §5.9 row would claim a transmit rule for a packet Ze never transmits. The extraction records site 5.9:4 as excluded against this row. The row's text, level and id are unchanged.
