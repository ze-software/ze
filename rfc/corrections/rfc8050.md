# RFC 8050 corrections

Why a requirement row of `rfc/short/rfc8050.md` changed level, text, or citation,
or was retired. The summary is the working document; this file is the record the
ratchets read (`internal/le/rfc/check_ratchets.go`).

Retired 2026-09-27: `RFC8050-x-5` states no obligation RFC 8050 carries. Read §1,
§2, §3, §4, §4.1, §4.2, §5 and §6, then the whole text: no sentence tells an MRT
parser that does not know the add-path subtypes to skip a record with an unknown
subtype. RFC 6396 does not state it either: its only such rule is §4.3.3, that an
implementation not recognising the AFI and SAFI of a RIB_GENERIC record SHOULD
discard the rest of that record, which is a different rule. No test tagged the
retired row, so no tag moved.
