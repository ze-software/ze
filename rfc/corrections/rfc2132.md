# RFC 2132 corrections

Retired 2026-09-29: `RFC2132-2-1` binds the authors of option definitions published after RFC 2132, which Ze does not implement: Ze sends only options RFC 2132 itself defines. Read §2, §3 to §9 and the whole text. Its one tag, on `TestEveryEmittedOptionHasLengthOctet`, proved the length octet of options RFC 2132 defines, and moved to `RFC2132-2-5`, which states that obligation. Extraction site 2:3 is now excluded as binds-another-role.

Correction 2026-09-29: `RFC2132-2-5` is a new row over the §2 sentence "In the case of some variable-length options the length field is a constant but must still be specified." The keyword is lowercase, so the row keeps MUST under D-3. The extractor reads uppercase keywords only, so the §2 section entry of `rfc/extraction/rfc2132.json` lists it under `unsourced-ids`.
