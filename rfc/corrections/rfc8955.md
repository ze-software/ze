# RFC 8955 corrections

Why a requirement row of `rfc/short/rfc8955.md` changed level, text, or citation,
or was retired. The summary is the working document; this file is the record the
level ratchet and the retirement check read (`internal/le/rfc/check_ratchets.go`).

Retired 2026-10-02: `RFC8955-6-2` quotes an RFC 8955 sentence that RFC 9117, which
updates RFC 8955, replaces. Read §6 of RFC 8955, then RFC 9117 §4.2 and §7: §4.2
quotes this sentence ("Section 6 of [RFC8955] states:") and redefines it as a
comparison of the left-most AS of an eBGP Flow Specification route with the
left-most AS of the best-match unicast route, and §7 makes the original rule
optional again. Ze implements the replacement and deliberately accepts the route
server case the original sentence forbids, so no test could prove this row and
none should. Under owner decision D-10 the obligation lives where it is stated:
RFC 9117 is enrolled with row `RFC9117-4.2-1`, and the two tags on
TestFlowSpecAuthorizationFromReceivedUpdates moved there (D-15 approval
2026-10-02), with RFC 8955 extraction site 6:4 now excluded as cross-document.
