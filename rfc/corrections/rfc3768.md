# RFC 3768 corrections

Correction 2026-09-30: `RFC3768-8.2-4` is a new row. `RFC3768-6.4.3-1` cites §8.2 but
quotes only the §6.4.3 bullet, so the §8.2 sentence "the Master virtual router MUST
respond to the ARP request with the virtual MAC address for the virtual router" was
dropped: what the answer must carry, beyond answering at all. Extraction site 8.2:1,
which was excluded as a duplicate of 6.4.3-1, now maps to the new row. It is restated
by RFC9568-8.1.2-6 and carries the same wire tests (non-owner and owner ARP reply
captures) in both polarities.

Correction 2026-09-30: `RFC3768-6.4.3-9` keeps its MUST level after review. Its text is
the Master-state pseudocode ("else: o Discard ADVERTISEMENT"), which carries no BCP 14
keyword of its own, but §6.4.3 opens the list it belongs to with "While in this state,
a VRRP router MUST do the following:", so the level is the RFC's. The row stays as it is.
