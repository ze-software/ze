# RFC 9136 corrections

Correction 2026-10-08: `RFC9136-3.1-4` drops "It MUST be all bytes zero otherwise." Restore that sentence together with its explicit ESI antecedent. Keep the existing gap; parsing/carrying a ten-octet identifier does not satisfy the semantic selection. No overlay-index implementation is commissioned. Current audit has no entry. ParseEVPN Type5 dispatch copies ESI and WriteTo copies it back without an Overlay Index model. First unimplemented judgment with producer map is owed, not semantic enforcement inferred from codec preservation.
