# RFC 4213 corrections

Correction 2026-09-30: `RFC4213-3.6-1` quoted the first sentence of the Section 3.6
source check and dropped the two that follow it, "This check also applies to packets
that are delivered to transport protocols on the decapsulator. This is done by
verifying that the source address is the IPv4 address of the encapsulator, as
configured on the decapsulator." The narrowing audit of spec-rfc-verdict-test-fix-pass
found the second one. The row now quotes all three: they state one obligation, the
last two say how it is met and where it applies, and the tagged tests prove it at the
boundary Ze owns. Ze installs the configured remote on the sit link it creates, the
kernel sit decapsulator compares every outer source against it before the inner
packet reaches any protocol, and Ze refuses an unspecified remote, which would make
that comparison match every source. The row's `{not-applicable}` marker is removed:
Ze fills the decapsulator role through the Linux sit datapath it installs
(ai/rules/rfc-compliance.md).
