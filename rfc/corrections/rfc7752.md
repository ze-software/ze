# rfc7752 correction records

Correction 2026-10-06: `RFC7752-3.3.1.3-1` quotes the Node Name recommendation only. §3.3.2.7 separately states for the Link Name TLV: "The use of FQDN or a subset of it is strongly RECOMMENDED." The link is a different named object, so `RFC7752-3.3.2.7-1` now preserves that recommendation separately rather than treating the Node Name row as its proof. The Link Name TLV is optional and the RFC also permits any operator-chosen string. `decodeLinkName` in `internal/component/bgp/plugins/nlri/ls/attr_link.go` decodes the supplied name; `originateAttributes` in `internal/component/bgp/plugins/ls_export/export_encode.go` copies supplied values and provides no FQDN-based link-name selection. `TestLinkNameRoundTrip` in `internal/component/bgp/plugins/nlri/ls/attr_test.go` proves only a string round trip, not this recommendation. The new row records that missing native naming support as a gap, not conformance or permission to implement the optional feature. Existing Node Name evidence is unchanged. The old Node Name supersession annotation is narrowed to its actual Node Name quotation; the new Link Name row points to RFC9552-5.3.2.7-1.
