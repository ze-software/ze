# RFC 5176 corrections

Why a requirement row of `rfc/short/rfc5176.md` changed level, text, or citation,
or was retired. The summary is the working document; this file is the record the
ratchets read (`checkLevelRatchet`, `checkRetiredRequirements`,
`internal/le/rfc/check_ratchets.go`).

Retired 2026-09-29: `RFC5176-3.5-2` quoted the same §6.1 sentence as RFC5176-6.1-1, "A Dynamic Authorization Server MUST silently discard Disconnect-Request or CoA-Request packets from untrusted sources." Read §2.3, §3.5 and §6.1: the sentence appears once, in §6.1, so the two rows were one obligation, and RFC5176-6.1-1 keeps it with its own positive and negative tags. The retired row's two tags, on TestCoAListenerInvalidAuth and TestCoAListenerUnknownSession (internal/component/l2tp/plugins/authradius/coa_test.go), proved the discard of a packet whose Request Authenticator is wrong. The RFC5176-3.5-1 tags on the same two units already state that claim, so the tags were dropped and the tests stay.
