Configuration Reference

The complete Ze configuration in one place: 36 sections (27 provided by plugins, the rest core), generated live from the YANG schema with ze yang tree. Every level -- sections and the containers inside them -- is browsed the same way: pick a setting to step into it, or search across the whole configuration. Where a setting is provided by a plugin, its owner and YANG source are shown. See the Configuration guide for a narrative walkthrough of BGP peer config specifically.
