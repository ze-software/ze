A terminal demo is an asciicast. The page replays terminal events as selectable text, so you can copy a command. The browser demonstration uses a WebP screenshot and a transcript, not encoded video. The recordings use no public service, and the terminal player is served from this site.

Each demo also appears beside the documentation for the feature it exercises. The transcript below each player provides the same command sequence without replaying the recording.

Continuous live configuration showcase

One independently recorded session starts with ExaBGP migration and the live BGP dashboard. The migration preserves the neighbor's identity, local and remote AS numbers, and configured hold time. The session then loads, proves, diagnoses and repairs eight features on the same running Ze daemon.
