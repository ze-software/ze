## Description

Every participant on the message bus (peers, groups, compiled-in plugins, and external programs) registers the messages it sends and receives, and with nothing written that registration is what runs; operators override delivery on the participant in a `bus { }` block or centrally under `bus { endpoint ... }` and `bus { participant ... }` using `send` (`allow`, `to`, per-message/tag filters) and `receive` (`allow`, `from`, per-message/tag filters).
