## Description

YANG `pki {}` config for CA certificates and device certificates with private keys. Every certificate and key leaf takes a PEM document or base64 DER, PKCS8/SEC1/PKCS1 private key detection, `$9$` sensitive encoding for keys, chain validation, expiry checking, atomic reload. PEM export for IPsec and TLS consumers. `ServerTLSMaterial` gives a TLS listener the leaf plus every stored intermediate, so the web/API HTTPS listener (`environment.web.certificate`), the looking glass (`environment.looking-glass.certificate`) and the as112/geodns DoT/DoH listeners (`tls { certificate }`) can serve an operator certificate with its full chain. A configured name that does not resolve is an error, and no listener falls back to the self-signed certificate. Health check (degraded at 30 days, down when expired). Report bus warnings for approaching expiry. `show pki certificates`, `show pki certificate name <name>`, and one command per export form: `pem`, `bundle pem` and `fingerprint`. Shared infrastructure for IPsec, TLS, and future mutual-auth features. The package has a second half config does not reach: a local certificate authority. Ze generates one root at its first start, keeps it in ZeFS, and issues its own components' certificates from it, so a peer validates an ISSUER rather than a copy of one leaf. The root lives ten years, an issued leaf 24 hours, and every certificate backdates `NotBefore` by five minutes for clock skew. A listener does not outlive its leaf: it answers each handshake through `plugin.ServingLeaf`, which reissues once two thirds of the current leaf's life is spent. Three surfaces consume the root today: the plugin transport (the engine hands it to every plugin child as `ZE_PLUGIN_CA_PEM`), the managed hub's listener, and `ze appliance init`, which issues the appliance's web leaf from an appliance root. The operator-facing web, looking-glass and DoT/DoH listeners are unchanged and still self-sign when no certificate is named. `show pki local-ca pem` exports the root certificate for an operator to paste into another node's `pki { ca <name> { certificate } }` block; the root private key has no accessor and reaches no command, no log and no config dump.
