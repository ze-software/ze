# Read by the native Go `le htmx-upgrade check` action, which scans every
# package that embeds htmx.
#
# One row per (file, category):
#
#     <path from the repository root> | <scanner category> | <why it does not apply>
#
# The categories the scanner emits: removed-attr, renamed-attr, inheritance,
# renamed-event, removed-event, swap-syntax, ext, old-event, old-api,
# renamed-config, removed-config, removed-header.
#
# A row fails the gate BOTH ways. An issue no row explains is unexplained and
# red. A row that explains no issue is stale and red: an exemption that has
# stopped matching is how an allowlist becomes a place to hide.
#
# A reason states a property of the markup, never a schedule. "The cutover has
# not reached this file yet" is not a reason -- it is the work.
#
# EVERY ROW BELOW IS AN INHERITANCE CARRIER, and each one says the same thing in
# its own site's terms: the attribute belongs to the request the CARRIER itself
# makes, and no descendant reads it. The scanner flags a carrier whenever any
# descendant issues a request, whether or not that descendant carries its own
# copy (checkInheritance in the native scanner), so a row here is the reading
# the scanner cannot do. The population is the rendered markup, not this list:
# 271 golden fixtures were parsed for carrier/descendant pairs, and the six
# distinct relationships they hold are the ones described below.
#
# Where a descendant would have been changed by the loss, it was measured in a
# real browser against htmx 4.0.0-beta6 rather than reasoned about, and the row
# says what was measured. The tree vendors 4.0.0 since 2026-09-02, and no row
# has been re-measured against it. Two differences were read out of the shipped
# bytes: the SSE extension renamed its events, and the core gained hx-query and
# hx-action. The core dispatches the same 33 event names in both builds, and the
# extension still swaps an unnamed message into the connecting element and
# dispatches a named one as a DOM event. Nothing was read that changes what a
# row below asserts, and nothing below rests on a fresh measurement.
