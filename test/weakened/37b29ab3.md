# Test weakenings this commit accepts

No test leaves the suite and no coverage goes with it. Ten functions in
`internal/component/plugin/register_test.go` are RENAMED, one for one, because
the command they exercise is renamed: `show plugins` becomes `show plugin list`
(owner directive, 2026-09-08). A test's name states what it proves, so a test
naming a command that no longer exists is a stale claim.

The gate reads the rename as ten deletions because it matches on the function
name, and the `t.Run` counts it reports as `1 -> 0` and `2 -> 0` are the same
artifact: the subtests moved with their parent. `git diff --numstat` over the
file is 46 lines changed against 46 added, and the file's assertion count is
unchanged against `HEAD`.
