# Test weakenings this commit accepts

One test is MOVED, not removed, and the move is what makes its assertion able
to fail.

`TestRegistrationCarriesTheDeclaredCommands` proved AC-4: a reader answers a
plugin's declarations without starting an engine. It lived in
`internal/component/plugin/all/all_test.go`, where it swapped every
`RunEngine` for a recorder and then read `reg.Commands` directly. Nothing in
that package is a reader, so no code path under the stub could reach a
`RunEngine`, and its `len(started) > 0` guard could never receive the value it
rejects. An independent review named it: AC-4 was argued structurally rather
than demonstrated.

It now lives in `internal/le/command/list/commandlist_test.go` and drives
`Collect`, a real catalog reader, under the same stub. The guard was proved to
fire: adding `_ = registration.RunEngine(nil)` to `Collect`'s plugin loop
reports `reading the declarations started 92 engine(s)`.

| Test | Reason |
|------|--------|
| TestRegistrationCarriesTheDeclaredCommands | Moved from `internal/component/plugin/all/all_test.go` to `internal/le/command/list/commandlist_test.go` in the same commit. The package it left holds the composition root and no reader, so its no-engine assertion was inert there. The package it joins holds `Collect`, so the assertion now guards a real path. Nothing left the suite: `internal/component/plugin/all` gains `TestEveryDeclaredShapeIsOneStage1Accepts` in this commit, which walks every registration and holds each declared spelling to what `validateShapeDecls` accepts. |
