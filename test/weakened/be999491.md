# Release roadmap assertion changes

The cutover removes the manually maintained pending-spec cards. The new roadmap
cases exercise committed inventory changes, full and partial builds, escaping,
source links, matching JSON and Markdown, and unique route ownership.

Whole-page wording goldens do not define the new content contract. Existing
feature ordering, legend, shell, navigation, count, and error checks remain.

| Test | Reason |
|------|--------|
| TestTheFeaturesPageKeepsTheDataFilesOwnOrder | Removed ordering assertions for retired pending-spec cards. Every retained section and feature card must still appear in declared order. |
| TestTheFeaturesPageReadsAsThePublishedPage | Removed the obsolete whole-page and mirror goldens, which pin the retired static backlog. `TestFeaturesLinkTheCanonicalRoadmap` checks the replacement link and absence of pending cards. Other feature tests retain the existing content contracts. |
| TestEveryDocsProducerSourceExists | Removed the fixed page-count assertion when the roadmap route transferred to its own producer. Source existence and duplicate-destination checks remain; the roadmap build test checks one route owner. |
| TestTheSharedHeaderReadsAsThePublishedHeader | Removed the whole-header wording golden after the roadmap description changed. Navigation entry, count, placeholder, error, and named-artifact tests remain. |
| nav_test | The aggregate assertion count falls because the obsolete whole-header golden was removed, as described above. No separate navigation behavior was removed. |
