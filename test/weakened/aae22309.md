# Test weakenings this commit accepts

Every row is a doctor check that moved to the package owning the config it
reads. The test moved with it, case for case, and the doctor package kept no
copy because the check it drove no longer exists there. The commit is correct
without each row because the owner package holds the same assertion over the
same check body, now reached through `diagnostic.RegisterDoctorCheck`.

| Test | Reason |
|------|--------|
| TestXfrmAuthTruncLen | the truncation lengths moved into `TestXfrmAuthName` (`internal/component/ike/dataplane/xfrm_linux_test.go`), which now asserts name and `truncLen` off one `xfrmAuthTransform` table for sha1/sha256/sha384/sha512; the `unknown -> 128` case it also carried asserted the silent default this commit removes, and `TestXFRMStateRefusesUnknownAlgorithm` asserts the refusal in its place |
| modelEnum | `internal/plugins/ospf/yang_vocabulary_test.go`: the helper became a one-line wrapper over `modelEnumIn`, which carries the three assertions it held (module loaded, leaf found, leaf holds an enumeration) so a second module can be read by the same walk; nothing asserted left the file |
