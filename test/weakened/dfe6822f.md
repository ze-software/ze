# Test weakenings this commit accepts

Three PATHS-LIMIT codec tests are REPLACED, not dropped. Each one's assertion
is carried by a test in the same file that checks more than the test it
replaces, and the three replacements were written in the same working tree as
the deletions.

The deletions came with the PATHS-LIMIT implementation this commit lands, and
this session verified each replacement at the assertion rather than at the
name.

| Test | Reason |
|------|--------|
| TestParsePathsLimitEmpty | Replaced by `TestPathsLimitEmptyRoundTrip`, which parses the same zero-length capability and asserts the same empty entry list, and adds two things the old test could not see: the exact encoded bytes `{76, 0, 2, 0}`, which pin `Len` for zero entries, and a Route Refresh capability after it, which proves a zero-length PATHS-LIMIT does not eat the capability that follows it. draft-abraitis-idr-addpath-paths-limit-04 Section 3 gives that encoding a meaning ("the sender doesn't have any specific limits to communicate"), so the parse must succeed and must not consume more. |
| TestParsePathsLimitShortRead | Replaced by `TestParsePathsLimitMalformed`, which covers the one length the old test tried (3) plus 1, 2, 4 and 254, a truncated value, and a truncated header. It also asserts `ErrorData(err)` carries the offending TLV, which the old test did not check, and which is what a NOTIFICATION needs to name the capability that caused it. |
| TestPathsLimitLen | Its four rows were `{0, 1, 2, 50}` entries against the `2 + 5n` formula. The formula is now pinned at both ends by exact byte assertions rather than by a restatement of itself: `TestPathsLimitEmptyRoundTrip` requires `{76, 0, 2, 0}` for zero entries, and `TestPathsLimitMaximumValue` requires `buf[1] == 255` for 51 entries, which is the largest value a one-octet length can carry. Every other row was the same arithmetic between those two points. `TestPathsLimitRoundTrip` and `TestPathsLimitBoundary` size their buffers with `Len()` and then parse what `WriteTo` produced, so a `Len` that disagreed with the encoder fails them. |
