# Test weakenings this commit accepts

Two tests left `internal/le/docvalid/helpshape_schema_test.go`. Each one
asserted a behavior this commit REMOVES, and every assertion it carried that
still holds is carried by a named test in the same file.

Every other row is a RENAME: the Go field that holds a command's long
explanation was `LongHelp` and is now `Description`, the field that holds its
one-line summary was `Description` and is now `ShortHelp`, and each test that
named the old field in its own name now names the new one. The body, the
fixture and the assertion of each one are the same function under the new
name, in the same file, in this commit.

| Test | Reason |
|------|--------|
| TestDisabledLoggerNotRegistered | It asserted that a logger created from `ze.log.<subsystem>=disabled` is absent from `ListLevels`, with the reason "users seeing disabled subsystems they can't change". The commit makes `disabled` a level a `slog.LevelVar` holds, so such a logger IS registered, `show log levels` reports it as `disabled`, and `request log level <subsystem> info` enables it. The replacement `TestDisabledLoggerRegisteredAndEnabledLater` (`internal/core/slogutil/slogutil_test.go`) asserts the new contract: listed as `disabled`, silent, then enabled by `SetLevel`. |
