# Test weakenings this commit accepts

| Test | Reason |
|------|--------|
| TestCheckFailsClosedForEveryLedgerShape | The gate is reading FIXTURE DATA, and its own known limits say so: the case this commit adds writes the string `"package a\nfunc TestA(t *testing.T) {\n\tt.Skip(...)..."` into a temporary repository, so the literal `t.Skip` appears in the test file and the detector counts it 0 to 1. Nothing is skipped: the function has no `t.Skip` call, and `TestCheckMatchesProducerDiagnosticsAndExitCodes` in the same file has written that identical fixture body since before this commit. The function GAINS assertions rather than losing them. It asserted that an absent ledger fails the live shape check, which was a fact about one shared file and cannot be stated about a directory of shards. In its place it now asserts three things: an absent shard reads as a session holding no rows, a weakening with no shard is still REFUSED, and that refusal names the shard and carries the two-column table header the author has to write first. The fail-closed contract therefore moved to where the absence decides something, and `SelfTest` (`internal/le/testweakened/selftest.go`) makes the same pair of checks over its own fixture repository. |
