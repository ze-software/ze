# Test weakenings this commit accepts

Six tests leave `internal/component/l2tp/plugins/shaper/filter_rate_test.go`.
None leaves the suite. `parseFilterRate` moved out of the shaper package and
became `traffic.ParseFilterIDRate`, because the RADIUS CoA listener needs the
same reader and cannot import a plugin package. Its unit tests moved with it, to
`internal/component/traffic/filterid_rate_test.go`, where the same five valid
spellings and the same five rejected inputs are driven through two table-driven
functions.

The file that kept the name was rewritten to test the chain instead of the
helper, which `ai/rules/evidence.md` asks for: it drives every one of those five
spellings through `(*shaperPlugin).onSessionUp`, the entry point a RADIUS
Access-Accept really reaches, and asserts that BOTH rates land on an interface.
The old body asserted the parser's return values and could not have caught the
defect this commit closes, which is that the upload half reached nothing.

The assertion count falls from 16 to 6 because ten `require` calls in six
functions became two loops over a case table. The case count rises: five valid
forms and five invalid ones are checked at the entry point, and the same ten are
checked at the parser in the traffic package.

The previous content of this shard explained `TestDefaultMetric`, and it was
spent by commit 1753e1f4c9, where git keeps it. A shard describes the commit
being prepared, so it is rewritten rather than appended to.
