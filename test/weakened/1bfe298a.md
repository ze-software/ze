# Test weakenings this commit accepts

One helper leaves `internal/component/sysrib/distance_bootstrap_test.go`, and it
leaves because it was renamed while gaining a second answer. Nothing the suite
checked stopped being checked.

`readsSeam(file, alias) bool` answered one question: does this file ask the
distance seam for a value. `seamCalls(file, alias) (reads, forwards bool)`
answers that question with `reads`, from the same walk over the same AST and the
same two method names, and adds `forwards`. So every input that made `readsSeam`
true makes `reads` true, and every producer the gate judged before it is still
judged.

`forwards` exists because the population gained a member of a new KIND. The
engine's forked-route-install handler now reads the seam
(`internal/component/plugin/server/dispatch_route.go`), and it stamps no protocol
of its own: it re-resolves the name the ROUTE arrived with and falls back to the
distance that route already carried. The gate's rule -- a seam reader names a
declared protocol as a literal and declares a `DefaultAdminDistance` constant to
pair with it -- has nothing to compare there, because both the name and the
bootstrap belong to the producing package and are checked in it.

The escape is narrow by construction. It applies only when EVERY seam call in
the file writes down neither argument as a literal, and only when the package
declares no bootstrap constant at all. `OrDefault("ospf", x)` and
`OrDefault(p, 110)` each carry a literal, so each is still a producer's call and
still checked. `noLiteralArgument` is the whole test, and a package that gains a
constant loses the escape.

`checkProducer` gained the corresponding arm, and it fails closed the same way
the rest of the check does: a package that forwards AND declares a constant is
reported, because then there is a bootstrap value with no leaf to check it
against.

The previous content of this shard explained the plugin-restart guard, and it was
spent by commit 31003a0dbf, where git keeps it. A shard describes the commit
being prepared, so it is rewritten rather than appended to.
