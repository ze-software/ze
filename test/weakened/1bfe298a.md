# Test weakenings this commit accepts

One test loses statements and gains coverage. `TestDefaultMetric` asserted three
derivations inline; it now drives seven through a table, so the assertion COUNT
falls from five to four while the cases rise from three to nine. Nothing left the
suite.

The contract it tests changed in the same commit. `DefaultMetric` took bits per
second and now takes Mbit/s, which is what the `reference-bandwidth` leaf and the
kernel both speak, so every operand in the old body would have been wrong by a
factor of a million. It also clamps at `MetricMax` instead of returning an error
above it, and the new body asserts that clamp, which the old body did not.

| Test | Reason |
|------|--------|
| TestDefaultMetric | Rewritten for the Mbit/s contract this commit introduces. Three inline derivations become a seven-row table, and the two error cases are kept: a zero link speed and a zero reference bandwidth. The new body additionally asserts both clamps, which the old one asserted neither of. The statement count falls because a loop replaced three blocks, not because a property left |
