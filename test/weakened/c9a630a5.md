# Test weakenings this commit accepts

One test is RENAMED, not removed. It asserted the one-wildcard-SA model that
commit `fed1c8f3c0` retired, and its new name says what it asserts now.

| Test | Reason |
|------|--------|
| injectQuotedICMPv4Error | A helper in `internal/component/gtsm/gtsm_rfc5082_linux_test.go`, renamed `injectICMPv4Error(source, outerTTL, quoted)`. No test and no case left the suite. The old helper pinned the outer source to the peer and built the quoted datagram itself from a port; the spec's whole point is that the outer source is not what associates the error with the session, so the source became a parameter and the caller builds the quote (`sessionQuote`, `quotedTCPv4Datagram`, `quotedTCPv4DatagramWithOptions`). Every injection the old helper performed is performed by the new one under a subtest named for its source (from the peer, quoting the BGP port; at TTL 255; quoting another port), plus the third-source and options cases the old signature could not express. |
