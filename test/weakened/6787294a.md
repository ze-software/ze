# Test weakenings this commit accepts

| Test | Reason |
|------|--------|
| TestRFC5880ForgedFirstPacketDoesNotSeedReplayFloor | It asserted that a first packet whose digest fails leaves bfd.AuthSeqKnown at 0. Owner decision D-14 (2026-09-27) follows RFC 5880 Section 6.7.3 literally, which seeds bfd.RcvAuthSeq before the digest step, so the test asserted the opposite of the required behavior. TestRFC5880FirstPacketSeedsReplayFloorBeforeDigest asserts the new order (the failed first packet is discarded and has set the floor), and TestRFC5880KnownSequenceNotReseededByForgedPacket asserts that a forged packet never re-seeds a known floor. |
