# Test weakenings this commit accepts

One test leaves `internal/component/bgp/plugins/cmd/cache/cache_test.go`, and it
leaves because what it asserted WAS the defect this commit closes.

`TestHandlerCacheForwardMissingSelector` called
`handleCacheForwardRPC(ctx, []string{"42"})` and asserted an error. It passed,
and the error it pinned is the one an operator got for every single use of the
command.

`send bgp <selector> cached <id>` puts the selector on the CONTEXT, not in the
arguments. `matchCommandTokens`
(`internal/component/plugin/server/command.go`) consumes the token after `bgp`
into `ctx.Peer` and returns only the tail, so the handler receives exactly one
positional: the id. `handleCacheForwardRPC` still guarded on a SECOND positional
and `handleBgpCacheForward` still read the selector from the first, which is the
layout of `request cache forward <id> <selector>`, the path the command left on
2026-09-05. Every forward therefore answered
`usage: request cache forward <id> <selector>` and sent nothing, while naming a
path the command tree no longer has.

So the removed test asserted that the single-argument call -- the ONLY shape the
live grammar can produce -- is an error. Keeping it would have required keeping
the defect.

Its replacement in the same file, `TestHandlerCacheForwardMissingID`, drives the
same entry point and keeps the missing-argument polarity that the suite is owed:
it calls `handleCacheForwardRPC(ctx, nil)`, asserts the error, and additionally
asserts the usage line now names `send bgp <selector> cached <id>`. The selector
is not among the arguments this handler can miss, because the command registers
`RequiresSelector` and `Dispatch` refuses it before the handler runs
(`TestSendRefusesAMissingSelector`,
`internal/component/plugin/server/send_test.go`).

Two further cases in the same file changed argument lists rather than leaving:
`TestHandlerCacheForward` and `TestHandlerCacheBatchPartialFailure` passed a
selector as a second positional, which the live dispatcher never delivers.
`TestHandlerCacheForward` now sets `ctx.Peer` and asserts the reactor received
that selector, which is coverage the old shape did not have.

The suite gains a case it never had. `TestEverySendFormReachesItsHandler`
(`internal/component/plugin/server/send_test.go`) dispatches all nine send forms
at a server built with no reactor: a form that binds its arguments can only fail
on the reactor, so a form that never bound them is the one thing that shows. Its
RED was observed by restoring the old guard.

| Test | Reason |
|------|--------|
| TestHandlerCacheForwardMissingSelector | Asserted that a one-argument call to `handleCacheForwardRPC` is an error. Under `send bgp <selector> cached <id>` that is the only call the dispatcher makes, so the assertion pinned a command that refused every input. Replaced by `TestHandlerCacheForwardMissingID`, which keeps the missing-argument polarity at the same entry point and also pins the usage line to the live path |
