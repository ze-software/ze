# Test weakenings this commit accepts

One row, and it is a restatement rather than a loss.

The stored-route replay used to emit one UPDATE per stored prefix. It now
rebuilds the message framing the source sent, coalescing the prefixes that share
an attribute block back into one UPDATE. That is what makes an egress policy
reach the same decision on the replay rail as on the live forward, which is the
defect this commit fixes.

A test that counted DISPATCHES was therefore counting the framing, not the
behavior. The requirement it exists for is untouched and is still asserted.

## The ExaBGP compatibility commit

Seven more rows, and every one is a RENAME or a rewrite in place. No assertion
left the suite: each row names where its subject is asserted now, and each of
those files is in the same commit.

The pattern behind six of them is one change. A function that used to take
20-bit label VALUES now takes RFC 3032 Section 2.1 stack ENTRIES, and a
function that used to turn operator text into wire bytes was named `Parse*` in
a package where `Parse*` means wire-to-type everywhere else. Both were renamed
so the name says which of the two jobs it does, and a test named after the old
function is renamed with it.

| Test | Reason |
|---|---|
| TestWriteLabelStack | RENAMED to TestWriteLabelValues (internal/core/bgp/nlri/helpers_test.go), with every table case carried over unchanged. WriteLabelStack now writes stack ENTRIES and WriteLabelValues writes bare labels, which is what this case always drove. TestWriteLabelStackKeepsTheTrafficClass is NEW beside it and asserts the half that had no test: an entry a peer sent survives a parse and a re-encode with its traffic class intact |
| TestWriteLabelStackOffset | RENAMED to TestWriteLabelValuesOffset, same file, same assertion, for the same reason |
| TestParsePrefixSIDSRv6Integration | RENAMED to TestEncodePrefixSIDSRv6Integration (internal/component/bgp/config/routeattr_test.go), body unchanged, for the same reason as the row below |
| TestParsePrefixSIDSRv6_ReservedFieldsZero | RENAMED to TestEncodePrefixSIDSRv6_ReservedFieldsZero (internal/component/bgp/config/routeattr_test.go). `ParsePrefixSID` was the operator-text ENCODER in a package where every other `Parse*` decodes the wire, and attribute 40 gained a real wire decoder in this commit, so the two could not share the name. Body unchanged |
| TestMUPBasic | REPLACED by TestMUPHeaderFields and TestMUPRoundTrip (internal/component/bgp/plugins/nlri/mup/types_test.go). The old case could only assert the header, because ParseMUP kept the route type body opaque; the new ones assert the header AND every field of all four route types the body now decodes |
| TestMUPFull | REPLACED the same way. Its constructor, NewMUPFull, is deleted in this commit: it had no non-test caller and it built a shape the parser no longer produces |
| TestMUPWriteToMatchesBytes | REPLACED by TestMUPRoundTrip, which asserts the same property over ten payloads rather than one, and by TestMUPUnknownRouteTypeKeepsOctets, which pins that a route type ze does not decode still re-encodes byte for byte |
| TestMUPStringCommandStyle | REWRITTEN in place, same name, same file. Its table drove the deleted constructors; it now drives ParseMUP over the wire, which is the only producer left |
