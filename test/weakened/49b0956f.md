# Test weakenings this commit accepts

One test leaves the suite and no coverage goes with it. `TestZZProbeExtended`
never asserted anything about what ze produced.

Its body loops the announce entry point over four combinations of update groups
and body size, calls `require.NoError`, and writes the message count to
`t.Logf`. A defect in the announce path that changed those bytes, dropped a
message, or emitted the wrong ones would leave it green, so it could not go red
for any product reason. Its own header called it a "Throwaway probe", and it
landed inside `3f25545edb`, a fix commit that did not need it.

The announce path it touched is covered by the tests that assert on what it
writes, `zzprobe_announce_extended_test.go` being the only file in the package
whose name says it is a probe rather than a test.

Removed at the owner's instruction, 2026-09-08.

| Test | Reason |
|------|--------|
| TestExpandASPath2to4 | The function it drives moved from `internal/component/bgp/plugins/rib/storage/attrparse.go` to `internal/core/bgp/attribute/as4.go`, and the test moved with it into `rfc6793_reconcile_test.go` under the same name. A test cannot call an unexported function across a package boundary, so staying was not an option |
| TestCanonicalizeASPath | Same move, same file. `canonicalizeASPath` is now unexported inside `internal/core/bgp/attribute`, reached through the exported `ReconcileASPathFamily`, and `rfc6793_reconcile_test.go` drives both |
| attrparse_test | The two cases above are what left this file. Nothing else changed, and every remaining case still drives `storage.ParseAttributes` |
| TestReconstructionCostsNothingWithoutAS4Path | An allocation assertion over `canonicalizeASPath`, which moved. `TestReconcileCostsNothingWithoutAS4Path` asserts the same cost in `internal/core/bgp/attribute/rfc6793_reconcile_test.go`, at the function's new home |
| rfc6793_reconstruct_test | The case above is what left this file in THIS commit. The 13 that remain are phase-2 residue of the same move and are still red: they call `storage.ParseAttributes` directly and assert a reconstruction that now happens upstream of it. Ten have exact-name successors in the attribute package. They are named in the commit body and left for the owner, because deleting a test file is his decision |
