# Test weakenings this commit accepts

One test leaves the suite and no coverage goes with it. `TestZZProbeExtended`
never asserted anything about what ze produced.

Its body loops the announce entry point over four combinations of update groups
and body size, calls `require.NoError`, and writes the message count to
`t.Logf`. A defect in the announce path that changed those bytes, dropped a
message, or emitted the wrong ones would leave it green, so it could not go red
for any product reason. Its own header called it a "Throwaway probe", and it
landed inside `3f25545edb`, a fix commit that did not need it.

The announce path it touched is covered by the tests that assert on what it
writes, `zzprobe_announce_extended_test.go` being the only file in the package
whose name says it is a probe rather than a test.

Removed at the owner's instruction, 2026-09-08.

| Test | Reason |
|------|--------|
| TestTranscodeASPath_2to4_Aggregator | Removed with the code it drove. `TranscodeASPath` no longer widens: the ingest collapse reconciles the AS-path family once per received UPDATE and relabels the payload four-octet, so the 2 to 4 direction has no caller and is now REFUSED with `ErrASPathSourceNotASN4` rather than performed. Its two assertions both have successors over the code that does the widening now: the AGGREGATOR widening in `TestCollapseAS4RewritesAggregatorToFourOctets`, whose header already says the 2 to 4 cases of this file land there (R-6), and the absence of an AS4_AGGREGATOR in `TestCollapseAS4DropsALoneAS4Aggregator` and `TestCollapseAS4DiscardsAS4AttributesFromNewSpeaker`. It carried no `RFC requirement:` tag, so no ledger binding moves with it. The new refusal is covered by `TestTranscodeASPathRefusesATwoOctetSource` in the same file |
| aspath_transcode_test | Four assertions leave with `TestTranscodeASPath_2to4_Aggregator`, whose row sits beside this one. The direction that test drove cannot arise once the AS-path family is reconciled at ingest: `TranscodeASPath` now refuses a two-octet source with `ErrASPathSourceNotASN4` rather than answering it, and `TestCollapseAS4RewritesAggregatorToFourOctets` (`internal/component/bgp/wireu/aspath_collapse_test.go`) carries the same widening cases at the site that performs the widening now |
