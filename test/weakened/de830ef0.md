| Test | Reason |
|------|--------|
| rfc2385ObserveUnsignedSYNACK | Moved the wire predicates into rfc2385CheckUnsignedSYNACK and return its error through the joined observer channel. The parent test calls Fatal before cleanup on any error. Initial signing, observed SYNACK injection, same-connection SYN retransmission, retained digest and the dial timeout remain checked; no worker calls FailNow. |
| assertRFC2385Digest | Returns errors instead of calling Fatal from a possible observer goroutine. Privileged Linux wire execution and native producer-break records passed. |
| rfc2385Option | Returns malformed-length, boundary-crossing and duplicate-option errors instead of terminating an observer goroutine. Digest and unsigned-packet callers check those errors; no malformed option became acceptable. |
| receive | Propagates receiveFrame failures and capture exhaustion to callers, which fail their parent test. The packet remains copied before the stack buffer is reused or returned. No capture failure became an empty successful observation. |
| receiveFrame | Returns configured-link and IPv4/TCP length failures instead of calling Fatal inside observers. The same link identity, total length, IP-header and TCP-header bounds remain enforced, and callers check the returned error. |
| TestPeerASDerivationReachesEveryCIFile | Moved walk, discovery and nonempty-population failures into peerASCorpus, whose error the test treats as fatal. Excludes only root decode/exabgp-compat dialects and unpromoted drafts before discovery; every native ParseFailed now fails. Exact AS declarations remain checked, with new negative native-corpus cases. The Linux race run parsed 1999 native records. |
