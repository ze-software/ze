# Test weakenings this commit accepts

Every test below proved one behavior: that repository checks skip
`plan/verification-evidence/`. The owner removed that directory on
2026-09-24, and this commit removes the exemption helper and every skip
branch that called it. A test of a guard that no longer exists guards
nothing, so each one leaves with the code it tested. The path-cleaning half
of `TestProposedVerificationArchiveIsExcludedBeforeReads` stays, renamed
`TestProposedCleansAPathThatLeavesItsDirectory`.

Later commits in this session land work from sessions that have ended. Their
rows are copied verbatim from the reason file that session wrote
(`test/weakened/916ee49e.md` or `7e722ae0.md`), so each weakening lands with
its reason.

| Test | Reason |
|------|--------|
| TestOSPFv3NSSADefaultPBitFollowsForwardingAddress | Losing the forwarding address now flushes the P-set NSSA default LSA (MaxAge) instead of re-originating it with the P-bit cleared, so the two assertions on the re-originated body describe removed behavior. The test asserts the flush. |
| TestRFC4577CryptographicAuthImplemented | The signKey inspection (key resolves, AuType cryptographic) left; the test keeps the end-to-end sign-then-verify round trip over md5 and hmac-sha-256, which fails if the chain does not resolve a cryptographic key, and now also carries the RFC4577-6-2 tag. |
| TestRFC4577InterfaceUsesConfiguredCryptoAuth | Its claim (the configured chain signs every packet on the link) moved onto TestRFC4577CryptographicAuthImplemented; engine-level signing on a configured interface is asserted by the auth_wiring tests. |
| TestRFC4577VirtualLinkGivesArea0Adjacency | The RFC 4577 VPN-PE role is outside the owner's 2026-09-21 scope. The backbone synthetic interface a resolved virtual link produces is asserted by TestVirtualLinkTopologyEmitsBackboneInterface. |
| TestVirtualLinkCostTracksTransitTopology | Same removal of the SPF change flag. The transit cost driving the runtime cost is asserted by TestVirtualLinkResolutionDrivesRuntime. |
| TestVirtualLinkCostUpdateNoFlap | The SPF computer no longer reports a per-resolution change flag: the callback now fires after every SPF so the engine can pick up endpoint addresses learned from LSAs. The engine reconciler (onVirtualLinksResolved) only re-sets the same cost on an unchanged resolution with a live interface and originates nothing; no test asserts that idempotence directly any more. |
| transitarea_test | Assertion count falls by the two change-flag tests; the file gains TestVirtualEndpointDiffersFromTransitNextHop and builds its fixtures from real Router-LSAs. |
