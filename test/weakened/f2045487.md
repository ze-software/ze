# Test weakenings this commit accepts

Every test below proved one behavior: that repository checks skip
`plan/verification-evidence/`. The owner removed that directory on
2026-09-24, and this commit removes the exemption helper and every skip
branch that called it. A test of a guard that no longer exists guards
nothing, so each one leaves with the code it tested. The path-cleaning half
of `TestProposedVerificationArchiveIsExcludedBeforeReads` stays, renamed
`TestProposedCleansAPathThatLeavesItsDirectory`.

Later commits in this session land work from sessions that have ended. Their
rows are copied verbatim from the reason file that session wrote
(`test/weakened/916ee49e.md` or `7e722ae0.md`), so each weakening lands with
its reason.

| Test | Reason |
|------|--------|
| TestAudClaim_MatchesCanonicalVariants | Canonical audience equivalence contradicted RFC 7519 StringOrURI identity; TestAudClaimMatchesExactIdentifier now accepts only the exact identifier and rejects URL-spelling aliases. |
| TestAudClaim_MatchesIDNCanonical | DNS equivalence does not establish JWT audience identity; TestAudClaimDistinguishesIDN now rejects a punycode claim for a different Unicode identifier while accepting the exact Unicode claim. |
| TestCanonicalAuthServerURL_IPv6 | The old expected values stripped an IPv6 issuer's explicit default port and trailing slash, transformations incompatible with the exact issuer identity required by RFC 8414 section 3.3. |
| TestCanonicalAuthServerURL_RejectsQueryFragment | The canonicalization helper was removed, while TestConfiguredIssuerQueryRejectedBeforeMetadataFetch preserves issuer-query rejection and TestOAuthHTTPSURL preserves fragment rejection. |
| TestCanonicalAuthServerURL_RejectsUserInfo | The obsolete canonicalizer was replaced by strict URL validation, with TestOAuthHTTPSURL rejecting userinfo and TestMCPOAuthIdentifierValidation rejecting credential-bearing issuer configuration. |
| TestNewStreamable_OAuth_AcceptsSlashDivergentAudience | Accepting a slash-divergent audience broadened token authority incorrectly; TestOAuthAudienceIdentity now proves exact-audience HTTP success and HTTP 401 for slash, query and Unicode aliases. |
| TestNewStreamable_OAuth_MetadataUsesCanonicalIssuer | Discovery must reject rather than normalize a differing issuer; TestOAuthRejectsIssuerAliases enforces that refusal and TestNewStreamable_OAuth_MetadataEndpoint retains the exact advertised authorization-server assertion. |
| TestSameAuthServer | URL-equivalent issuer spellings are not interchangeable under RFC 8414 section 3.3; TestOAuthRejectsIssuerAliases now rejects slash, path and query aliases before any JWKS fetch. |
| TestSameAuthServer_IDNCanonical | The old assertion incorrectly treated Unicode and punycode issuer identifiers as equal, contrary to RFC 8414 sections 3.3 and 4 requiring exact issuer identity without normalization. |
| TestValidateJWKSURI | JWKS transport no longer inherits an HTTP allowance from the issuer scheme; TestOAuthHTTPSURL and TestRFC8414JWKSMetadataSecurity enforce HTTPS and reject plaintext JWKS URLs or redirects before a plaintext request. |
| TestValidateJWKSURI_RejectsEmptyHost | TestOAuthHTTPSURLRejectsEmptyHost retains the same missing-host rejection through the replacement shared HTTPS URL validator. |
| TestValidateJWKSURI_RejectsMalformedAS | The former cross-URL helper was replaced by independent issuer and JWKS validation; TestOAuthHTTPSURL rejects malformed or non-HTTPS schemes and TestASMetadataURL rejects a schemeless issuer. |
