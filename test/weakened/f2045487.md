`plan/verification-evidence/`. The owner removed that directory on

nothing, so each one leaves with the code it tested. The path-cleaning half
of `TestProposedVerificationArchiveIsExcludedBeforeReads` stays, renamed
`TestProposedCleansAPathThatLeavesItsDirectory`.
