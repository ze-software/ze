# Test weakenings this commit accepts

| Test | Reason |
|------|--------|
| TestTheGrammarTakesEveryValueBehindAKeyword | The test is deleted with the function it drove. `parseOptions` was `doc wiring`'s own keyword parser, and it is gone because `check` now declares `changed-file` and `dry-run` and dispatches through `leaction`, whose `parseArguments` does that job for every area. Four of its five assertions are re-made at the ENTRY POINT: a keyword with nothing after it (`./le doc wiring check changed-file` answers `argument keyword "changed-file" requires <path>`), a removed option and a bare positional path (both `unknown argument keyword ...; use one of: changed-file, dry-run`), all three now covered by `TestEveryPublishedVerbIsDispatchedThroughItsOwnTable` (`internal/le/actions_test.go`), which probes every published verb of every area rather than this one. The fifth, that `changed-file` repeats and that a path spelled like a keyword is a value rather than a flag, had NO cover after the deletion: `leaction` tests the shared `Repeat` contract but nothing asserted that this area declares it. `TestCheckDeclaresTheKeywordsItEnforces` is added in the same commit to hold it, and it discriminates by asserting the field. Verified live: `./le doc wiring check changed-file dry-run changed-file b.go` exits 0 with `dry-run` read as the first path. |
| TestNamedToolFailureKeepsItsReportAndCode | Two assertions left it and neither states a fact the test can still make. It asserted `answer` was a `leaction.Sweep` and that `len(sweep.Ran) == 1`, then reached into `sweep.Ran[0].Answer` for the `gaterun.ActionReport`. A line naming ONE action now answers that action's own payload rather than a one-row envelope, so there is no `Ran` to count: `answer.(gaterun.ActionReport)` succeeding IS the proof that exactly one action answered, because a multi-verb line still answers a `Sweep` and would fail the assertion. The unwrapping is the whole diff. Every assertion the test is named for is untouched and still made against the same report: the exit code, the action, the argv, the environment suffix and the run directory. |
