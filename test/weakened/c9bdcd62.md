# Test weakenings this commit accepts

| Test | Reason |
|------|--------|
| testESPGroupPFS | A helper in `internal/component/ike/engine/child_test.go`, not a test and holding no assertion: it built an `ipsec.ESPGroup` with PFS on. It has zero callers anywhere in the tree. Its successor is `pfsESPGroup(mode)` in `child_rekey_pfs_test.go`, which takes the mode as an argument and is what the PFS rekey tests use with `ipsec.PFSEnable`. Nothing the suite demonstrates moves: the successor covers the same construction and more of it. The stale cross-reference in `testESPGroup`'s doc comment is repointed in the same change. |
| entryASPath | A helper in `internal/component/bgp/plugins/rib/storage/rfc6793_reconstruct_test.go` that read an interned AS path back off a `RouteEntry`. Zero callers: the tests that used it were removed by `58e79f57e2`, which moved the RFC 6793 Section 4.2.3 reconstruction to `internal/core/bgp/attribute` and verified every successor by name. It is not a test and states no property of the product; its two `require` calls are the helper's own preconditions on the entry it was handed. |
| rfc6793_reconstruct_test | The file's assertion count falls from 8 to 6, and both that left are the two inside `entryASPath` above. No test function lost an assertion and no test function changed: the gate counts assertions per FILE, so a helper carrying its own preconditions out of the file reads as a weakening. `TestParseAttributesCostsNothingExtraWithoutAS4Path` and `TestParseAttributesReconciliesNothing` are untouched, and the ten dead wire fixtures removed beside the helper have byte-identical, actively used successors in `internal/core/bgp/attribute/rfc6793_reconcile_test.go`. |
| TestCommandTree | The assertion count falls from 18 to 17 because the test checked for a root `peer` node that the command tree can no longer hold. The send-bgp migration moved announce, withdraw, raw and update out of the root `peer` container to `send bgp <selector> <form>`, and deleted that container; the client builds this tree from the registered RPC paths, so the node the test required was one no RPC declares. `send` is ADDED to the top-level list in its place, and that addition is what proves the migration reached the client tree. The fallback-tree check moves to the same footing. The test now names the root an operator reaches the four forms at, which is the property it was written to hold. |
