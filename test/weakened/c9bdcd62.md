# Test weakenings this commit accepts

| Test | Reason |
|------|--------|
| TestTheNamedFileFormNeedsAKeywordBeforeEachPath | The test is deleted with the function it drove. `namedFiles` was `ste`'s own keyword parser, and it is gone because `check` now declares `file` and dispatches through `leaction`, whose `parseArguments` does that job for every area. Its three assertions are re-made at the ENTRY POINT rather than against a private helper, which is stronger: `TestCheckIsDispatchedThroughItsOwnTable` drives `Answer` with `{check docs/a.md}` for the bare positional and `{check file}` for the keyword with no value, both wanting 2, and `TestEveryNamedFileReachesTheRatchet` drives two `file` pairs and asserts `FilesExamined == 2`, where the old test only checked that a helper returned two strings. Three cases the old test could not reach are added: `file -xh`, `file --help file docs/a.md`, and a stray trailing word. Verified live: `./le ste check zzprobe x` answers `unknown argument keyword "zzprobe"; use one of: file` and `./le ste check file` answers `argument keyword "file" requires <path>`. |
