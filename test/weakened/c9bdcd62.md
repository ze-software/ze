| requireEveryJobAdvisory | Deleted because it asserted the DEFECT it was written to prevent, which is the one case `ai/rules/testing.md` allows a test to change what it claims. It demanded `continue-on-error: true` on every job of `.github/workflows/evidence-nightly.yml`. That key was removed deliberately by `7682286f9b` on 2026-09-02, and the workflow's own header records why: with it, "the workflow reported success while five of its six jobs failed". So the check was holding the workflow to the shape that hid its failures, and a repair of the workflow would have reddened it. `requireEveryJobStatesItsOwnVerdict` replaces it and refuses that key instead. Coverage is not reduced: the workflow is still held to being scheduled-only by `requireScheduledOnly`, so it gates no merge, and it is now ALSO held to every job reporting its own failure, which nothing asserted before. Discrimination observed rather than argued: `continue-on-error: true` was added back to the `fuzz` job, the test caught it with `job "fuzz" carries continue-on-error: true, so a failed run reports success`, and the file was restored byte-identically. `qemu-nightly.yml` still sets the key on three jobs and keeps only `requireScheduledOnly`, because widening the 2026-09-02 repair to a second workflow is a decision this change does not own. |
