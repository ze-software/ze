# Test weakenings this commit accepts

| Test | Reason |
|------|--------|
| nexthop_form_test | GUARD MOVED, not removed, and the new site is tested. The config parser refused a link-local `next-hop` outright, which was correct while RFC 2545 Section 3 was the only form ze knew: a link-local supplied as THE next hop had no global address to follow. draft-ietf-idr-linklocal-capability Section 3 defines a 16-octet field holding one link-local address, permitted only on a session that negotiated capability 77. The parser cannot answer that question, because one static route is advertised to many peers and the config knows neither the peer nor the negotiated state. So the decision moved to where both are known: `Peer.resolveNextHop` (internal/component/bgp/reactor/peer.go:1387) returns ErrNextHopLinkLocalOnly for a session that may not carry the form, and `rfc_draft_linklocal_send_test.go:158` asserts exactly that with require.ErrorIs. What the old test PREVENTED, ze emitting a 16-octet Next Hop whose only address is link-local where that is not allowed, is still prevented and now proven at the entry point that decides it, under the RFC requirement tag DRAFT-IETF-IDR-LINKLOCAL-CAPABILITY-3-1 negative. The renamed test asserts the parser keeps the address, which is the other half of the same contract. |
| TestParseRouteAttributesRejectsLinkLocalNextHop | Same move, recorded under the test's own name as well as the file's. The rejection this test asserted was correct while RFC 2545 Section 3 was the only next-hop form ze knew. draft-ietf-idr-linklocal-capability Section 3 defines a second form, legal only on a session that negotiated capability 77, and the config parser cannot answer a per-session question because one static route is advertised to many peers. The refusal now lives at `Peer.resolveNextHop` (internal/component/bgp/reactor/peer.go:1387, ErrNextHopLinkLocalOnly) and is asserted with require.ErrorIs at rfc_draft_linklocal_send_test.go:158 under the tag DRAFT-IETF-IDR-LINKLOCAL-CAPABILITY-3-1 negative. Nothing this test prevented became possible. |
