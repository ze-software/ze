# Test weakenings this commit accepts

Every test below drives a type, a field, or a method this commit deletes. The
subject is gone, so the test goes with it. None of them is replaced by a weaker
assertion: there is nothing left to assert against, because `IncomingRIB`,
`OutgoingRIB`, the wire-byte cluster on `rib.Route`, its reference counter and
its iterators had no caller outside these tests.

The one property that survives the deletion is per-attribute zero-copy, and it
did not live here. `TestAttributesWirePackFor` and
`TestAttributesWirePackForDifferentContext`
(`internal/core/bgp/attribute/wire_test.go`) hold the same-context and
different-context arms that `TestPackAttributesFor_ZeroCopy` and
`TestPackAttributesFor_Reencode` held against the route. Route storage and
best-path moved to the bgp-rib plugin, which carries its own suite.

Recorded by the session that landed the deletion of another session's staged
work under owner instruction. The spec that authorizes the deletion,
`plan/spec-rib-package-dead-surface.md`, stays in-progress in this commit.
