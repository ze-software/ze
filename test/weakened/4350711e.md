# Test weakenings this commit accepts

Six entries, and every one of them tested a behavior this commit DELETES. No
assertion about surviving behavior was dropped, and the two cases where the
behavior has a successor name the test that now carries it.

| Test | Reason |
|------|--------|
| TestDiscoveryIndexGateReadsOnlyTheHeaderTheMapDerivesFrom | It tested `checkDiscoveryIndex`, the commit-time freshness gate this commit deletes. The gate refused a commit that changed an index-feeding source and omitted `ai/PACKAGE-MAP.md`. The map is no longer tracked, so no commit can carry it and no commit can omit it. There is no behavior left for the test to assert. |
| TestCheckAndUpdateAgreeAboutOneTree | It asserted that `discoveryindex.Check` and `Update` answer the same content for one tree. `Check` is deleted: it existed only to compare a fresh render against the committed copy, and there is no committed copy. `TestUpdateWritesAMapOfTheTreeItRead` carries the half that survives, which is that `Update` writes what the walk read. |
| TestTheAreaHoldsBothNativeActionsAndOnlyUpdateWrites | It asserted the area registers two actions, `check` and `update`, and that only `update` writes. The `check` verb is deleted with the function behind it. The surviving claim, that the area's one action writes, is asserted by the action table test in the same file. |
| TestAStaleIndexAnswersTheCodeTheCommitGateReads | It asserted that a stale index answers with the code the commit gate reads. Staleness against a committed copy is the concept this commit removes: an artifact is either present and derived from the current tree, or absent. Neither state is stale, so the exit code it pinned no longer exists. |
| TestDiscoverySourceSeesAHeaderOnlyHEADStillHolds | It guarded `isDiscoverySource` in `internal/le/doc/wiring`, which joined the working tree with HEAD so that a REMOVED `// Package` header still counted as a change. The predicate is deleted with the verify stage that used it. Deleting it is what let the first invalidation predicate miss a removed header, which round 1 of the review caught as a BLOCKER. `IsSourcePath` replaces it by not asking about the header at all, and `TestRemovingAPackageHeaderStillInvalidatesTheMap` is the guard that now holds that case. |
| docwiring_test | The file's assertion count falls from 77 to 73. Every one of the four is inside the two deleted tests above, or inside the deleted `discoveryIndexesStage` arm for the package map. No surviving stage lost an assertion. |
