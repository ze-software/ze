# Test weakenings this commit accepts

Six entries, and every one of them tested a behavior this commit DELETES. No
assertion about surviving behavior was dropped, and the two cases where the
behavior has a successor name the test that now carries it.

| Test | Reason |
|------|--------|
| TestFeedsNamesTheIndexEachSourceDrifts | It tested `feeds`, which round 2 deletes as dead code. `feeds` served `IsSource` alone, and `IsSource` lost its last production caller when the previous commit deleted `checkDiscoveryIndex` and `isDiscoverySource`. A test is the only thing that kept either alive. |
| TestIsSourceAgreesWithTheWalkAboutTheFilesTheMapDescribes | Re-aimed rather than dropped. `TestIsSourcePathAgreesWithTheWalkAboutTheFilesTheMapDescribes` makes the same claim against the predicate that replaced it, with its expectation derived from `Build` rather than written by hand. |
| TestIsSourceAgreesWithPackageDocAboutTheTextTheMapDerives | Deleted, and this one is a real narrowing rather than a rename. It tested only the header clause: that a file merely MENTIONING `// Package`, or carrying one past `HeaderLines`, is not a source. `IsSourcePath` has no header clause, deliberately, because round 1 found that asking for a header is what made a REMOVED header invalidate nothing. All four of its fixtures now answer true on purpose, so its subject no longer exists. |
| discoveryindex_test | The file's assertion count falls from 50 to 48. Both sit inside the two deleted tests above. |
| TestSessionStartRebuildsAPresentArtifact | Inverted, because the behavior it asserted is the defect. It required session start to rebuild an artifact that is already present, which is what put a 4 to 6 second rebuild inside a 5 second hook budget. `TestSessionStartLeavesAPresentArtifactAlone` asserts the opposite and fails against the code this round replaces. |
