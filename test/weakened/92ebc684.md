# config import: the confirmation test is renamed and strengthened

TestConfirmImportReplace became TestImportConfirm when its helper was renamed
cmdImportConfirm after its caller. Every case moved across, each now asserts
both the text that must appear and the text that must not, and new cases cover
a failed read and the singular wording.

| Test | Reason |
|------|--------|
| TestConfigViewsWaitsAreNotSatisfiedByTheTypedCommand | Replaced by TestTapeWaitsAreNotSatisfiedByTheTypedCommand, which applies the same echo check to every demo tape including config-views, and TestSelfSatisfiedWaitsDiscriminates, which proves the detector flags a bad wait and passes an anchored one |
