# Argument binding tests move with the validator

`validateCommandArgs` and its helpers moved from `plugin/server` to the
`command` package as `command.ValidateArgs` (`argbind.go`), so the local-data
route and the daemon dispatcher call one validator. The tests that called the
unexported helpers moved with them, unchanged apart from the package qualifier,
to `internal/component/command/argbind_test.go`. Nothing left the suite.

| Test | Reason |
|------|--------|
| rfc7950StatementGrammar | Replaced in `internal/component/config/yang/loader_structure_test.go` by `rfc7950GrammarText`. The grammar is now parsed by shipped code (`parseStatementGrammar`) from the embedded `rfc7950.abnf`, and the test reads the RFC text to prove the embedded copy is the Section 14 code component byte for byte |
| TestYANGKeywordsMatchTheRFC7950Grammar | Superseded by `TestStatementGrammarsMatchTheRFC7950Grammar`, which keeps the same keyword-set and argument-less checks against `rfc/full/rfc7950.txt` and adds block and argument-rule checks. It runs alongside `TestEmbeddedGrammarIsTheRFC7950Grammar`. The `yangKeywords` and `argumentlessKeywords` sets the old test compared were deleted along with it |
