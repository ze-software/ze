# Argument binding tests move with the validator

`validateCommandArgs` and its helpers moved from `plugin/server` to the
`command` package as `command.ValidateArgs` (`argbind.go`), so the local-data
route and the daemon dispatcher call one validator. The tests that called the
unexported helpers moved with them, unchanged apart from the package qualifier,
to `internal/component/command/argbind_test.go`. Nothing left the suite.

| Test | Reason |
|------|--------|
| socketFilterDefs | Moved verbatim to `internal/component/command/argbind_test.go` with the tests that use it |
| permutations | Moved verbatim to `internal/component/command/argbind_test.go` with the tests that use it |
| TestPositionalDefPrefersConstrainedDef | Moved verbatim to `internal/component/command/argbind_test.go`: it calls `positionalDef`, now unexported in `command` |
| TestPositionalBindingIsOrderIndependent | Moved verbatim to `internal/component/command/argbind_test.go`, calling `ValidateArgs` there |
| TestPositionalDefKeepsTheMandatoryTierFirst | Moved verbatim to `internal/component/command/argbind_test.go`: it calls `positionalDef`, now unexported in `command` |
| rfc8907_command_test | The fatal assertions of the three moved tests left with them; the file also gains `TestDispatchNamesTheBoundOfAKeywordBoundValue` |
