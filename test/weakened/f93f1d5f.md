# Argument binding tests move with the validator

`validateCommandArgs` and its helpers moved from `plugin/server` to the
`command` package as `command.ValidateArgs` (`argbind.go`), so the local-data
route and the daemon dispatcher call one validator. The tests that called the
unexported helpers moved with them, unchanged apart from the package qualifier,
to `internal/component/command/argbind_test.go`. Nothing left the suite.

| Test | Reason |
|------|--------|
| TestPositionalBindingIsOrderIndependent | Not weakened in substance: `ValidateArgs` now answers a `command.ValidatedArgs`, which holds one positional binding (`bound`, `boundValue`) where the old `map[string]string` could hold several, so "bound to exactly one leaf" is the type's shape and the separate count check has nothing left to count. The remaining assertion, `Positional(tc.want)` found and equal to the token for every permutation, still fails on a binding to any other leaf |
