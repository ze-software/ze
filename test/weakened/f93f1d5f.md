# Argument binding tests move with the validator

`validateCommandArgs` and its helpers moved from `plugin/server` to the
`command` package as `command.ValidateArgs` (`argbind.go`), so the local-data
route and the daemon dispatcher call one validator. The tests that called the
unexported helpers moved with them, unchanged apart from the package qualifier,
to `internal/component/command/argbind_test.go`. Nothing left the suite.

| Test | Reason |
|------|--------|
| TestHelpShapeGateWalksAnRPCOutsideAnAPIModule | Not weakened: a Loader now refuses a load after Resolve (ErrLoaderResolved, batch 3 of spec-validated-construction-and-state-types), so the IPC fixture module is passed to shapeLoaderOver, which loads it before the one Resolve. The two t.Fatalf checks on that load and that Resolve moved into shapeLoaderOver unchanged; every assertion on the report is unchanged |
