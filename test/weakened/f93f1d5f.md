# Argument binding tests move with the validator

`validateCommandArgs` and its helpers moved from `plugin/server` to the
`command` package as `command.ValidateArgs` (`argbind.go`), so the local-data
route and the daemon dispatcher call one validator. The tests that called the
unexported helpers moved with them, unchanged apart from the package qualifier,
to `internal/component/command/argbind_test.go`. Nothing left the suite.

| Test | Reason |
|------|--------|
| TestCheckArgumentAcceptsAnyAlternative | Superseded by `TestDeviateArgumentChoosesItsProduction` in `loader_grammar_test.go`. `checkArgument` now takes one rule, because each deviate rule is its own production chosen by its argument, so the new test checks that "add", "delete", "replace" and "not-supported" each match exactly one deviate production and "remove" matches none, which is the old assertion made stricter |
