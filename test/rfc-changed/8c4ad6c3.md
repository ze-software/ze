The owner's approval for changing a test that carries an `RFC requirement:` tag.
One row per test. An author MUST NOT write a row for their own change: the row
records Thomas's decision, and an author writing it is a forgery rather than a
shortcut (`docs/contributing/rfc-implementation-guide.md`).

| Test | Reason |
| ------ | ------ |

Nothing else moved. The commit deletes the three-argument constructor, so every caller must pass the AS-PATH argument, and `nil` is what "this route carries none" was already spelled as inside the deleted one. A tagged test cannot avoid it. RFC4760-3-2 negative stays proven on the same Next Hop Network Address length in the same message, with the same quoted requirement. |
