# RFC-tagged test changes this session's commits carry

The owner's approval for changing a test that carries an `RFC requirement:`
tag. One row per test. An author MUST NOT write a row for their own change: the
row records Thomas's decision, and an author writing it is a forgery rather
than a shortcut (`docs/contributing/rfc-implementation-guide.md`).

Thomas approved these four on 2026-09-14, in the sentence "approving the four
RFC-tagged OSPF test changes." Each of the four asserted the one-wildcard-SA
model that commit `fed1c8f3c0` retired (one XFRM state under `::`, which no
OSPF flow could resolve) and was red at HEAD. Each now asserts the
per-destination model that commit shipped; none asserts less than before, and
each carries a fresh discrimination record in `rfc/discrimination/`.

| Test | Reason |
|------|--------|
| TestIPsecInstallOnInterfaceUp | Owner approved, 2026-09-14. An esp interface installs three states on link-up (ff02::5, ff02::6, the interface's own link-local) rather than one, and the protocol is asserted on every state. RFC4301-4.5-1, RFC4552-3-2 and RFC4552-11-3 are proven over every installed state. |
| TestIPsecSAIsWildcardWithOSPFSelector | Owner approved, 2026-09-14. Renamed `TestIPsecSAPerDestinationWithOSPFSelector`. The {::/0, ::/0, proto 89} selector assertion is unchanged. |
| TestSAParamsSharedKey | Owner approved, 2026-09-14. RFC4552-6-5 is asserted over every SA the interface builds rather than the single wildcard one; the key and SPI equality it pins are unchanged. |
| TestAHSAIdentifiedBySPIAndProtocol | Owner approved, 2026-09-14. Supersedes the CALL SITE ONLY row in `c9bdcd62.md`. The RFC4302-2.4-1 claim now states the {SPI, destination} identifier of the section's first search step: the body asserts the destination is ff02::5 rather than the `::` wildcard, and that the source alone is wildcarded. The SPI and protocol assertions are unchanged. |
