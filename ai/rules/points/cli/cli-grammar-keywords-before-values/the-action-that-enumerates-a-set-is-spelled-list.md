**A command whose action enumerates the members of a set MUST spell that action `list`, and MUST NOT spell it `ls`, `dir`, `all`, or any other abbreviation.** One concept carries one name (`ai/rules/writing.md`, habit 1), so an operator who learned `show env list` never guesses a second spelling at the next noun. An action that enumerates something OTHER than the members of the set its noun names is a different concept and takes a different word: `show data registered` answers the key patterns the code declares, not the keys the store holds. Ze is unreleased, so a second spelling MUST be renamed outright rather than aliased.
