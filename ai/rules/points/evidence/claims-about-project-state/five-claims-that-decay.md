**This section governs claims about the PROJECT, not claims about code. Five shapes decay, and a stale one redirects a session, so each MUST be re-verified before you act on it:**
- "this is not implemented"
- "this is an open question"
- "this needs a decision"
- "this cannot be tested here"
- "this is out of scope"

**A specification, a design note, a journal row and an agent report all carry them.** A wrong fact is cheap because the next read contradicts it. A stale FRAME is expensive because nothing contradicts it: you inherit the author's picture of the problem and then do competent, well-tested work that answers a question the tree stopped asking.
