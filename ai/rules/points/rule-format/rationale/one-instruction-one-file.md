One instruction is one file because the unit of enforcement was one rule file, and a rule file holds hundreds of instructions. Nothing named the sentence a check enforced. Nothing counted what a refusal had prevented. Nothing said whether a reworded instruction still had a gate behind it. The path is the id, so a machine answers the first two: `make ze-rules-gate-map` names the point each check enforces, and a refusal cites that point. The third is answered in REVIEW. A `Binding` carries no digest of the point body, so rewording a body under the same slug leaves the binding green. What the path buys there is that the reword is a one-file diff a reader sees.
