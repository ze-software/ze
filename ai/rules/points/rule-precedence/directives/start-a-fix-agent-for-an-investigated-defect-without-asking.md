**A defect whose investigation is complete, naming its cause at the producer and a concrete fix plan, MAY be handed to an implementation agent by the main thread without asking Thomas first.** The permission holds only while the fix touches no file another in-flight agent is changing and runs no whole-tree gate that would disturb test work in progress. The main thread MUST still ask before a fix that needs a product choice no RFC, agreed design or owner meta decision answers, or that changes an RFC-tagged test. Restoring correct behavior is never that choice (M4), and the fix MUST still pass independent review before it lands.
