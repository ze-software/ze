**A defect whose investigation is complete, naming its cause at the producer and a concrete fix plan, MAY be handed to an implementation agent by the main thread without asking Thomas first.** The permission holds only while the fix touches no file another in-flight agent is changing and runs no whole-tree gate that would disturb test work in progress. The main thread MUST still ask before a fix that needs a scope decision, changes behavior Thomas has not decided, or changes an RFC-tagged test, and the fix MUST still pass independent review before it lands.
