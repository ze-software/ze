**Every subagent brief MUST carry the spec path, the phase it owns, the `ai/rules/` files that govern it, the parent session ID, the exact per-session scratch path, and what the report has to contain; a brief whose agent will write Go MUST name `docs/contributing/ze-go-style.md` as a precondition in its opening, never under a closing heading, where it is read after the code already exists.** A subagent types its identity line, `export ZE_AGENT_ID=<agent>; export CLAUDE_CODE_SESSION_ID=<parent>; `, in front of every Bash command that is not made only of readers such as `grep`, `sed` and `cat`: the session id makes it share the parent's session directory and scratch, while the `ZE_AGENT_ID` gives it a commit namespace and a spec claim of its own. Its start text prints the line, and the Bash hook checks it, never adds it, and refuses a command that needs it with the line to type (`docs/contributing/running-commands.md`, "Session identity, and what each agent owns"). It resolves symbols with `gopls` from Bash when its registry carries no LSP tool. How an editing agent lands its change, and the export a brief MUST NOT ask for, is `ai/rules/precommit-verify.md`.
