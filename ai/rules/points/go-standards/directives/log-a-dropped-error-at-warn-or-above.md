**An error that is caught and not returned MUST be logged at WARN or above, and MUST NOT be logged at debug or info.** The code goes on as if the operation had happened, so the log line is the only record that it did not, and debug is off on every running system: a source-address lookup that failed with EPERM, logged at debug, left an IKE SA on its old address with nothing in the log. Dropping an error is correct only where going on is correct; a WARN does not make a default correct. `./le arch refuse-by-default check` refuses the shape on the lines a change touches.
