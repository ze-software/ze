# Thomas's own setup

This folder describes the machines and tools Thomas, the project's owner, uses
to develop Ze. It is committed so that agents on each of his machines get it
through git. It is not part of Ze and is no guide for anyone else: if you are a
contributor, or an agent on any machine not listed in `machines.md`, nothing
here applies to you, and the hosts, paths and tunnels it names do not exist for
you.

| File | What it covers |
|------|----------------|
| `machines.md` | His two development machines, how an agent tells which one it is on, and what it may do on the other one |
