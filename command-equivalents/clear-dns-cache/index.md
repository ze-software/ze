# `clear dns cache`

## Ze command

- Syntax: `clear dns cache`
- Registry path: `clear dns cache`
- Mode: Daemon
- Wire method: `ze-clear:dns-cache`
- Global pipes: yes

Flush all DNS cache entries and reset all DNS cache counters.
