# `show schema list`

## Ze command

- Syntax: `show schema list`
- Registry path: `show schema list`
- Mode: Read-only
- Wire method: `ze-show:schema-list`
- Global pipes: yes

List all YANG schemas loaded by the daemon. Shows module name, namespace, and revision for each schema.
