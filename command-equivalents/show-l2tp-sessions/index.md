# `show l2tp sessions`

## Ze command

- Syntax: `show l2tp sessions`
- Registry path: `show l2tp sessions`
- Mode: Read-only
- Wire method: `ze-l2tp-api:sessions`
- Global pipes: yes

List all active L2TP sessions. One line per session: local/remote ID, parent tunnel, subscriber login, and uptime.
