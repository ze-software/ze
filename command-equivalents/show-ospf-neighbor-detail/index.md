# `show ospf neighbor detail`

## Ze command

- Syntax: `show ospf neighbor detail`
- Registry path: `show ospf neighbor detail`
- Mode: Read-only
- Wire method: `ze-show:ospf-neighbor-detail`
- Global pipes: yes

Show full per-neighbor state (spec-ospf-ext-14): DD sequence, decoded Options (incl. the RFC 5250 O-bit), request/summary list sizes, last NSM event, and timers.
