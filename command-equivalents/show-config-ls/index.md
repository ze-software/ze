# `show config ls`

## Ze command

- Syntax: `show config ls`
- Registry path: `show config ls`
- Mode: Read-only
- Wire method: `ze-show:config-ls`
- Global pipes: yes

List all configuration files stored in the database. Shows archived snapshots and the active config.
