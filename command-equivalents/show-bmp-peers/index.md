# `show bmp peers`

## Ze command

- Syntax: `show bmp peers`
- Registry path: `show bmp peers`
- Mode: Read-only
- Wire method: `ze-show:bmp-peers`
- Global pipes: yes

Show BGP peers as seen through BMP monitoring. Lists peers reported via BMP with their state and route statistics.
