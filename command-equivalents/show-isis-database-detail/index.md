# `show isis database detail`

## Ze command

- Syntax: `show isis database detail`
- Registry path: `show isis database detail`
- Mode: Read-only
- Wire method: `ze-show:isis-database-detail`
- Global pipes: yes

Show the IS-IS link-state database with TLV detail. Expands each LSP into its decoded TLVs (type, length, value) so you can read exactly what each node advertises.
