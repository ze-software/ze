# Demonstrations

These recordings show how Ze behaves, and the labs let you try the same operations before deploying it.

- [Terminal demonstrations](terminal/): reproducible recordings of installation, configuration, and operator workflows.
- [Labs](../labs/): run protocol, forwarding, appliance, and interoperability tests.
- [netlab topology](../labs/netlab/): start a reusable three-node Ze topology under containerlab.
- [Use cases](../use-cases/): deployment examples with configuration for Ze and its neighboring routers, plus the checks for each setup.
