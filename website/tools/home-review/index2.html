Reasons to investigate

One system to configure and operate.

Ze combines a network OS with an extensible configuration and protocol engine. The practical differences are in how you manage it, extend it and inspect what it does.

Operate

Connect directly to Ze.

Ze runs its own SSH server, CLI and configuration editor. You can operate it without a host shell, then use the web interface or APIs to reach the same configuration model.

Explore CLI interaction →
Extend

Add services through plugins.

The core supplies configuration and shared runtime services. Compiled Go modules and external processes extend Ze, so your automation can use its plugin interfaces.

Understand the engine →Develop a plugin →

Read the definitions Ze uses.

Command and configuration references come from the definitions used by the program. A website build updates those references when the definitions change, including settings supplied by plugins.
