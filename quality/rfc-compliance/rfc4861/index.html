Enrolment

Enrolled: Ze is an IPv6 router that originates Router Advertisements and answers Router Solicitations on configured interfaces (internal/plugins/iface/ra) and on L2TP subscriber sessions (internal/component/l2tp/ppp ra_send.go), and sends VRRP unsolicited Neighbor Advertisements (internal/plugins/vrrp/transport/na.go). Walked site by site on 2026-10-26 (rfc/extraction/rfc4861.json). Every MUST is classified: the rows the Linux kernel's Neighbor Discovery performs (Neighbor Solicitation and Advertisement, address resolution, NUD, Redirect, host processing of Router Advertisements) are lower-layer; the rows on Router Advertisement origination, Router Solicitation handling and unsolicited Neighbor Advertisements are Ze's and carry tagged tests where Ze meets them; thirteen of them are gaps, listed under Support remaining; the ND proxy and IPsec rows are among them, because no owner ruling names either feature unwanted (ai/META-DECISIONS.md, Goal and scope).

What the public ledger says

Status: Partial

What the ledger says is covered Router Advertisements with M and O flags, router lifetime, reachable and retrans timers, Source Link-Layer Address, Prefix Information and RDNSS options, sent with Hop Limit 255 from the link-local address on a randomized schedule, answered to a solicitation after a random delay, rate limited, and withdrawn with a zero router lifetime when an interface stops advertising. Router configuration variables are bounded as Section 6.2.1 requires. Neighbor Discovery other than Router Advertisement origination is performed by the Linux kernel.
What the ledger says remains A received Router Solicitation is not checked for Hop Limit 255, Code 0, length or zero-length options (RFC4861-6.1.1-2, RFC4861-4.6-1). The configuration does not cover every conceptual variable (RFC4861-6.2.1-1), and the advertised reachable-time, retransmit-timer and hop-limit are not the values the router itself uses (RFC4861-6.2.1-8). An interface that is not forwarding still advertises, and turning forwarding off does not zero the Router Lifetime (RFC4861-6.2.4-1, RFC4861-6.2.5-2). VRRP refuses no multicast IPv6 virtual address as a Neighbor Advertisement target, and does not space its repeated unsolicited Neighbor Advertisements by RetransTimer (RFC4861-4.4-3, RFC4861-7.2.6-1). A Router Advertisement can exceed the link MTU, because the prefix list is unbounded (RFC4861-9-7). No MTU option is sent. No Neighbor Discovery proxy exists (RFC4861-7.2.8-1, RFC4861-7.2.8-2), and Neighbor Discovery cannot be secured with AH or ESP (RFC4861-11.2-1, RFC4861-11.2-2).
