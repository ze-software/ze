Enrolment

Enrolled: IPv6 Stateless Address Autoconfiguration. Ze is a router on every interface and a host where the operator enables autoconf and accept-ra (netlink backend only). Linux addrconf (linux:CONFIG_IPV6) forms the addresses and runs DAD; ze writes the autoconf, accept-ra and forwarding sysctls (internal/component/iface/config_sysctl.go), exposes any other kernel key through its sysctl setting list, and reads the results over netlink. Six MUSTs are lower-layer rows on Linux autoconfiguration and address lifetimes, which no VPP path carries. Ten are gaps: the nine DAD rows hold on Linux but are unverified on the VPP interface backend, whose AddAddress runs no DAD, and the VPP interface backend runs no Router Advertisement processing (5.5-2). On Linux that processing is on by default: ze writes no accept-ra or autoconf sysctl for an unset leaf, so the kernel defaults accept_ra = 1 and autoconf = 1 stay in force, honoured only while forwarding is off
