Enrolment

Enrolled: IPv6 Router Advertisement Options for DNS Configuration: the RDNSS and DNSSL Neighbor Discovery options. Every MUST-level row is classified; each is a {gap}, because ze sends RDNSS as a router but sends no DNSSL and, as a host, processes no received RDNSS or DNSSL option.

What the public ledger says

Status: Partial

What the ledger says is covered:

Router side, RDNSS only: ze's Router Advertisements carry one RDNSS option (type 25, Length 1+2n, up to 127 addresses, one shared Lifetime) built by BuildRA in internal/core/ndp/ra.go.
What the ledger says remains No DNSSL option is sent (RFC8106-5.2-2, RFC8106-5.2-3, RFC8106-5.2-4). Ze as a host processes no RDNSS or DNSSL option from a received RA: no extraction, no ordered list, no Lifetime expiry, no length validation, no SEND preference (RFC8106-1.2-1, RFC8106-1.2-2, RFC8106-5.1-1, RFC8106-5.1-2, RFC8106-5.2-1, RFC8106-5.3.1-1, RFC8106-5.3.1-2, RFC8106-5.3.1-3).
